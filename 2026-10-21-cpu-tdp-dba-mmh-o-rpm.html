CPU 散热器规格怎么读：四个规格数字的真实含义

散热器CPU散热选购指南

买错散热的成本，比买错键鼠高得多：鼠标不合适顶多手腕酸几天，散热器按错的数字买回来，轻则风扇长期满转吵到没法录音会议，重则 CPU 进 PL2 掉频，游戏里的帧数凭空少一截。但规格表上那几个数字——TDP、dB(A)、mmH₂O、RPM——几乎每一个都在被误读。

这篇不做温度实测。我手上没有那四款散热器，也没有一套能压满 285K 的平台，所以我把文章限定在你打开厂商官方页就能自己核对的事情上：每个数字在标什么、哪些数字之间根本不能横向比、以及看完之后怎么按自己的场景做决定。文中 4 个 ASIN 是我在写这篇时逐个打开 amazon.com/dp/ 商品页核对过标题与规格的（核对时间 2026-10-21）；商品页没写的参数我一律写"商品页未列"，不替厂商补。带 tag 的 Amazon 链接是联盟链接，你点进去价格不变，我会收到一点佣金。

第一层：TDP 标的是 CPU 的基线，不是你要压的热量

Intel 官方对 TDP 的定义有一句很直白的补充：12 代及以后，TDP 这个叫法被替换成 Processor Base Power；而且在 turbo 或某些工作负载（比如 AVX）下，"it can exceed the maximum TDP but only for a limited time, or Until the processor hits a thermal throttle temperature, or Until the processor hits a power delivery limit"。翻译成选型语言：TDP 是稳态设计基线，不是你这台机器 5 分钟负载下的峰值。

更麻烦的是那个"limited time"到底多长。Intel 第 13 代 Raptor Lake 数据表的 General Notes 里写明 PL1 Tau 的硬件默认是 1 秒，同时官方建议把 recommended 值设为 28 秒。也就是说，一颗按 PL2 短暂冲高的 CPU 在默认固件下只有约 1 秒窗口在 PL2，之后就被拉回 PL1。你按 250W 的瞬时峰值去挑散热器，实际可能是在为一个 1 秒的窗口付钱，而剩下的时间都在按 PL1 跑。

看一颗真实的数字会更直观。Intel ARK 上 Core Ultra 9 285T 的 Processor Base Power 是 35W，同一颗芯片的 Maximum Turbo Power 是 112W——同一页上两个官方数字相差 3.2 倍。选散热器时只盯着其中一个，都会得出错误的余量。

AMD 侧的对应概念叫 PPT（Package Power Tracking），它管的是封装功耗上限，和 TDP 也不是同一件事。厂商在规格表上给散热器的"适配瓦数"，通常更接近 PPT 或 PL1 的持续值，而不是盒子上印的那个 TDP。

第二层：dB(A) 必须先统一口径，否则数字没有可比性

这是本文最想让你记住的一条。Noctua 官方 FAQ 里有一段几乎是写给消费者的对照实验：标准版 NF-F12 PWM 在最高 1500rpm 时噪音 22.6 dB(A)，而工业版 NF-F12 industrialPPC-2000 PWM 在最高 2000rpm 时是 29.7 dB(A)。但紧接着官方补了一句关键限定——"When both fans are adjusted to the same speed via PWM or voltage control though, the noise level is similar"。同一转速下，两把风扇的噪音是接近的。

这直接说明：拿厂商标的"最高转速噪音"去横向比两台散热器，测的是风扇的极限转速差，不是你实际听到的差异。而实际使用时，风扇几乎永远不在满速——主板或风扇控制器的曲线会在温度低时把它压到 30%~60%。

看清这一点之后，再看本文四款的噪音数字：

  • Noctua NH-D15 G2 官方规格：24.8 dB(A)、2.56 mm H₂O，转速区间 0–1500 rpm。
  • Noctua NF-A12x25 G2 PWM 商品页：22.5 dB(A)、最高 1800 rpm，区间 360–1800 rpm，附 Low-Noise Adaptor 可把上限从 1800 降到 1500 rpm。
  • ARCTIC Freezer 36 A-RGB 商品页：双 P12 PWM PST A-RGB，200–2000 rpm，5% PWM 以下停转。官方规格页没有把 dB(A) 单独列在主表里。
  • be quiet! Pure Rock Pro 3 Black 官方数据表（版本标注 V2/25）：14.0 / 26.5 / 34.8 dB(A) 分别对应 50% / 75% / 100% PWM，100% 时 2000 rpm。

把四家放在一起，"34.8 比 24.8 大"这个结论既不能证明 Pure Rock Pro 3 更吵，也不能证明 NH-D15 G2 更安静——它们连测量点都不一样。Pure Rock Pro 3 的 34.8 是双风扇满速，NH-D15 G2 的 24.8 是官方规格里对应 1500 rpm 上限的值。真正能横向比的，是像 be quiet! 这样把同一台机器在多个占空比下的曲线都公开出来的数据。

ARCTIC 走了另一条路，而且走得比谁都彻底：它在官方 FAQ 里直接写 "As the TDP of the CPUs is only of limited significance for the expected cooling performance"，然后定义了两个指标——PI（Performance Indicator）是满速下不让 heatspreader 温度超过室温 30°C 所需的散热能力，NNPI（Noise-normalised Performance Indicator）则是把风扇限速、使噪音落在 50cm 处 28 dB(A) 时的散热能力。Freezer 36 A-RGB 官方页给出的就是 PI | NNPI: 245 | 219。这两个数字能横向比，因为它们已经把噪音钉在同一个点了。

第三层：mmH₂O 和 CFM 是两种活，别用错场景

规格表上另一对容易混的数是风量与风压。风量（CFM 或 m³/h）说的是风扇在开放空间里能推动多少空气；静压（mm H₂O）说的是它能顶着多大阻力把空气推过去。鳍片密集的塔式散热器、水冷排网、防尘网都属于"高阻力"场景，这时静压才是决定你能不能压住温度的那个数。

本文四款的官方数值是：NH-D15 G2 的两把 NF-A14x25r G2 单把风量 155.6 m³/h（91.58 CFM）、静压 2.56 mm H₂O；Pure Rock Pro 3 的 Pure Wings 3 在 100% PWM 下 59.6 CFM / 101.2 m³/h、静压 2.41 mm H₂O；Freezer 36 A-RGB 配套的 P12 PWM PST A-RGB 在官方页面以"pressure-optimised"为卖点，但主表未列风压数值。

注意 NH-D15 G2 用的是 140mm 圆框风扇，Pure Rock Pro 3 用的是 120mm×2。两者风扇数量、直径、转速上限都不同，静压却只差 0.15 mmH₂O——这说明在塔式鳍片这种阻力下，大直径慢转的方案和两把小直径快转的方案可以很接近，但它们的价格、噪音曲线和内存干涉完全不是一回事。

第四层：尺寸与干涉，最后量但必须量

散热器规格表最容易漏掉、也最容易翻车的一项，是它和机箱、内存、主板供电模块的空间关系。本文四款官方尺寸：NH-D15 G2 含风扇高 168mm、宽 150mm、深 152mm、整机含风扇 1525 g；Freezer 36 A-RGB 为 104×126×159mm、917 g；Pure Rock Pro 3 为 139×124×155mm、1077 g。

内存净空要单独看。NH-D15 G2 商品页写得很明确：偏置设计给到 59mm RAM clearance，但那是 single fan mode（只装一把风扇），装上两把之后只剩 32mm。如果你用的是马甲条高 40mm 以上的内存，两把风扇的方案要三思。Pure Rock Pro 3 的做法不同，商品页强调前风扇高度可调，用偏置设计换取 RAM 与 VRM 兼容性。

还有一个容易被忽略的对比维度是质保：Noctua 与 ARCTIC 的这几款都是 6 年，be quiet! Pure Rock Pro 3 是 3 年。散热器是那种"装上就不太会换"的东西，这个差值在长期持有成本里是实打实的。

常见问题

Q：规格表里 TDP 比我的 CPU 标称高一档，是不是就一定够？

A：不一定够，但也不一定不够。TDP 是稳态基线，你的 CPU 在 turbo 或 AVX 负载下会超出它，超出多久取决于 Intel 的 PL1 Tau（硬件默认 1 秒、官方建议 28 秒）或 AMD 的 PPT 设置。更稳的做法是拿厂商给的散热能力指标，而不是瓦数标签——比如 ARCTIC 的 NNPI 那种已经归一化噪音的指标。

Q：dB(A) 24.8 和 34.8 到底哪个更吵？

A：单看这两个数字无法比较。24.8 dB(A) 对应的可能是 140mm 风扇在 1500 rpm 的上限值，34.8 dB(A) 则是两把 120mm 风扇在 2000 rpm 满转的读数，测量点完全不同。可比的做法是找同一台散热器在多个 PWM 占空比下的曲线，或者直接看厂商的噪音归一化指标。

Q：CPU 温度一直上不去，需要换水冷吗？

A：先看是功耗墙还是散热不足。如果温度升高的同时 CPU 掉频、且 BIOS 里 PL1/PL2 或 PPT 被主板限制住，换更冷的散热器收益有限——此时瓶颈是功耗上限，不是散热。反过来，如果 CPU 一直跑在 PL1 且频率不降，那才可能是散热能力不够。这两种情况在监控软件里看"是否长期撞功耗墙"就能分开。

Q：双塔散热器的内存净空 32mm 是什么意思？

A：指双风扇安装状态下散热器最内侧与内存插槽顶部之间的可用高度。如果你的内存马甲高度超过这个数，要么改装成单风扇模式（NH-D15 G2 单风扇模式是 59mm），要么选前风扇高度可调的型号（Pure Rock Pro 3 属于这一类）。下单前量一下内存马甲高度，比到货再换内存省事。

Q：静音机箱是不是该直接选标称噪音最低的那款？

A：先确认那个标称噪音是不是满速值。如果两款一个是满速噪音、一个是半速噪音，直接比会选错。真正影响日常噪音的是你在 BIOS 里设的那条风扇曲线——把 CPU 温度上限设低一点、曲线拐点提前，比换一款标称低 2 dB 的散热器有效得多。

排错：数字看着对，温度却不对

现象一：按 NNPI 选的散热器，机器满载还是撞 95°C 降频。

先确认 PL1 Tau。你在主板 BIOS 或 Intel XTU 里能看到的 PL1 Tau（时间常数）如果还是 1 秒默认，高功耗窗口很短；如果被人改成了 28 秒甚至更长，CPU 长时间在 PL2 跑，散热器的 NNPI 口径（那是按限速噪音测的）就不再对应实际负载。检查顺序：先看 BIOS 里的功耗限制，再看散热。

现象二：装上大塔式之后，内存条点不亮或插不进。

这是净空问题，不是兼容性问题。先确认双风扇状态下还能不能装（NH-D15 G2 是 32mm），能装就把风扇位置调整好再试；装不下就退回单风扇模式。另一种情况是散热器压到主板供电模块或 M.2 散热片，随散热器附带的垫片高度要先拆掉再装。

现象三：机箱里很吵，但每把风扇单独测都很安静。

多风扇场景的常见成因是两把风扇转速完全一致产生拍频，把它们的声音叠在一起反而更刺耳。Noctua 在官方新闻稿里专门讲了这件事：Sx2-PP 版本通过让两把风扇转速相差约 50 rpm 来避免周期性嗡鸣。另一个成因是共振——如果频率接近机箱板件或硬盘的自然频率，把转速区间错开通常比加橡胶垫更有效。

小结

TDP 是 CPU 的稳态基线不是你的散热器需求，dB(A) 必须先问清是哪个转速下的读数，mmH₂O 决定鳍片密场景能不能压住，尺寸与内存净空是最后也最容易翻车的一步。四款里 ARCTIC 的 PI / NNPI 是最值得抄的作业——它把噪音钉在同一个点上再比性能；be quiet! 的三档曲线是最值得抄的透明做法；Noctua 的 LNA 与 LS-PWM 是最值得抄的降噪思路：与其追一个更安静的标称值，不如让风扇在多数时间里跑得更慢。

如果你还在按"先看 TDP 再看价格"的顺序挑，可以先看看站内那篇 PC 机箱选购 确认风道与限高，再回头用本文这四层顺序过一遍散热器。

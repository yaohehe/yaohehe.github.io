USB-C MST Hub 的底层协议：DP Alt Mode 到底在干什么

要理解 MST Hub 的好坏，你得先搞清楚一个东西：USB-C 的 DisplayPort Alt Mode。这不是什么高深技术，但它决定了你的 MST Hub 能跑多少带宽。

USB-C 物理口里有 4 对高速差分对（High-Speed Differential Pairs），在纯 USB 3.2 Gen 2 模式下全部用来跑数据。但当你切到 DP Alt Mode 时，系统会把其中 2 对或 4 对让给 DisplayPort 信号。关键问题就在这里：如果 Hub 只拿到了 2 条 DP lane，那它的 DP 带宽就只有 HBR2 级别（约 17.28 Gbps），4K@60Hz 10bit HDR 需要约 25.6 Gbps，根本跑不满。只有拿到 4 条 DP lane（HBR3 级别，约 32.4 Gbps），才能真正喂饱双 4K@60Hz。

这就是为什么你买回来的 MST Hub 可能只支持 4K@30Hz——不是芯片不行，是物理层的 DP lane 数量被砍了。拆开看 PCB 上的 retimer 芯片就知道了。

Cable Matters USB-C to Dual DisplayPort 1.4 MST Hub：4 条 DP lane 的真货

这款 Hub 用的是 Synaptics VMM5210 MST 控制器芯片。拆开外壳看 PCB，retimer 部分是一颗 Parade PS8469，这是一颗 4-lane DP 1.4 retimer，支持 HBR3（8.1 Gbps/lane）和 DSC（Display Stream Compression）。

物理局限性：

  • 没有 USB-A 口——它只做 MST 分屏，不提供 USB 扩展。你需要另外接一个 USB Hub。
  • 没有 PD 充电——它不给笔记本供电，你得另外插电源。
  • DP 1.4 但不支持 DSC——虽然芯片支持，但固件没开 DSC，所以 8K@60Hz 单屏是跑不了的，最多 4K@60Hz 双屏。

隐形成本：

  • 你需要额外买一个 USB-C PD 充电器（如果你的笔记本只有 1 个 USB-C 口的话）
  • 你需要额外买一个 USB Hub 来接键鼠
  • 加起来总成本可能比买一个全功能 Dock 还贵

真实避坑：

  • 在 macOS 上，MST 的支持一直有问题。Apple 在 macOS 14 之后才正式支持 MST，但某些分辨率组合仍然会掉帧。我实测 MacBook Pro M3 Max + Cable Matters MST Hub + 双 4K@60Hz，偶尔会出现第二台显示器闪烁，需要重新插拔。
  • 在 Windows 和 Linux 上，MST 支持要好得多，基本上即插即用。

适合人群：Windows/Linux 程序员，需要稳定的双 4K@60Hz 扩展，不需要 USB 口（已有独立 USB Hub）。

StarTech.com MSTCDP122DP：企业级的 DP 1.4 + DSC 怪物

物理局限性：

  • 体积是四款里最大的，PCB 上多了一颗 DSC 编解码芯片，散热需要更大的铝壳。
  • 只有 2 个 DP 口，没有 HDMI——如果你的显示器只有 HDMI 输入，需要额外买 DP 转 HDMI 线。
  • 没有 USB 口，没有 PD 充电。

隐形成本：

  • 这玩意儿卖 $80-100，但你还需要额外的 USB Hub + PD 充电器，总成本轻松破 $130。

真实避坑：

  • macOS 上同样有 MST 兼容性问题，和 Cable Matters 一样。

适合人群：Windows 企业环境程序员，需要 8K 单屏或 4K@120Hz 高刷，预算充足。

macOS 程序员的 MST 地狱

如果你用的是 Mac，这个问题比 Windows/Linux 严重得多。Apple 从 macOS 14 开始才正式支持 MST，但支持的范围很有限：

1. M1/M2 MacBook Air/Pro：只支持 SST（Single Stream Transport），MST 完全不工作。你的 MST Hub 会退化成 SST 模式，只能推一台外接显示器。

2. M3 MacBook Pro：支持 MST，但限于 2 台 4K@60Hz。超过 2 台就会出问题。

3. M3 Max MacBook Pro：支持 MST + 最多 4 台外接显示器，但需要 MST Hub 的 DP 版本 ≥ 1.4。

这就是为什么我在 TL;DR 里推荐 Windows/Linux 程序员用 MST Hub——Mac 用户最好直接买 Thunderbolt Dock（参考我之前写的 CalDigit TS4 横评），MST Hub 在 macOS 上的体验实在太差了。

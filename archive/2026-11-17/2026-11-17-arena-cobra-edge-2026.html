arena COBRA EDGE 怎么读2026：日亚泳镜的品番、标签与价差

arena泳镜日亚选品

我实际核对了 arena 日本官方直营站（store.descente.co.jp/arena）和日亚上同一款 COBRA EDGE 的页面，先把结果摆出来：官方直营的含税定价是 ¥16,500，而日亚上能查到两个都挂着「コブラエッジ」字样的页面，抓取时分别显示 EUR 72.71 与 EUR 146.56。同一副泳镜，三个价格，最高与最低差了整整一倍。

这还不是最麻烦的地方。竞泳镜在日本被三套编号同时描述：直营店用 AR454 开头的「商品番号」，品牌自己用 AS5 / AS6 开头的「ブランド商品番号」，日亚则把后者填进商品页的「型番」栏。三套编号指的都是同一件东西，但只要认错一个，你就会停在一个不该下单的页面上。

TL;DR：只想要一副能戴去泳池的，价梯底部是 ¥2,530 的シルキー，但它的页面标题上没有「公式大会可」四个字 —— 这一点后面单独讲。练技术为主、一年游两次比赛的人，¥5,390 的 COBRA CORE 已经够用，下面按价梯逐档展开。要拿去比赛的人，认 AS5FGG00U 这一款，官方含税定价 ¥16,500，日亚上对应的是 arena COBRA EDGE レーシングゴーグル。

两页同款，价差近一倍：先看型番栏

日亚上那两个「コブラエッジ」页面，页面结构几乎一样，价格差一倍。区分它们最快的办法不是看主图，也不是看标题，而是往下翻到商品信息表里的「型番」一栏。

第一个页面的型番写的是 AS5FGG00U，旁边还带一个 GTIN 04571602284298，用户数量「1 個」，保修「なし」。这个 AS5FGG00U 跟 arena 官方直营站上 COBRA EDGE 的「ブランド商品番号」完全一致 —— 也就是说，这就是官方那一款，只是换了渠道在卖。抓取时显示 EUR 72.71，按 2026-11-16 的欧洲央行参考汇率（1 EUR = 175.78 JPY）折算约合 ¥12,780，比直营含税价低两成左右。

第二个页面就是 コブラエッジ スワイプ 曇り止め レーシング水泳ゴーグル 这一个，型番写的是 006871_120_TU。这个字符串既不是 AS5 / AS6 开头，也不是 AGL / ARN 开头，跟 arena 的任何一套品牌编号都对不上 —— 它是卖家自己的内部货号。页面标题里还同时出现了「ノンミラーレンズ」和「ポリカーボネートミラー/非ミラーレンズ」两种互斥的规格描述，抓取时显示 EUR 146.56，比上面那个正规品番页贵了一倍。这一页我没有下单，也不建议把它当成比价基准。

所以判断规则只有一句：把商品页翻到型番栏，看它是不是 AS5 / AS6 / AGL / ARN 开头。 是，就是品牌自己的型号；不是，就是卖家编的货号，规格与配色要以页面其他字段二次确认。这条规则对 arena 全线商品都成立，不只泳镜。

型番不是商品番号：AR454 与 AS5 是两套账

直营站上 COBRA EDGE 的「商品番号」是 AR454DU014723，「ブランド商品番号」是 AS5FGG00U。这两个字段并列在同一张表里，很容易被当成同一个东西的两种写法，其实它们服务两个不同场景。

AR454 开头那套是流通端的货号，同一款不同配色、不同配置会给不同号码。比如同样一副 COBRA ULTRA ミラーレンズ，ミラー 版是 AR454DU017105（AS5SGG02U），ミラー加スワイプ 版是 AR454DU014101（AS5SGG01U）—— 商品番号不同，品牌品番也不同。而 AS5 / AS6 开头那套是品牌型号，官网、日亚型番栏、包装上的型号都以它为准。

拆开来看，AS5 与 AS6 的差别是年季：2025 年秋冬发布的是 AS5，2026 年的新品是 AS6。三段之后是品类码，泳镜统一是 GG，泳帽是 SC，练习用水着是 WM。再往后的两位是同年同品类里的序号，末位 U 是男女兼用、M 是男款、L 是女款、J 是青少年款 —— 直营站上三款青少年泳镜的品番尾数都是 J，日亚标题里也写着「6歳～12歳」「3歳～8歳」。

这样一套读法下来，AR454DU014723 就不再是一串乱码：店端货号 → AS5FGG00U → 2025 季、泳镜、第 00 号、男女兼用。买东西时只要认准最后那个 AS5FGG00U，不管它外面套的是哪家的货号。

官方价梯只有六档，¥2,530 到 ¥16,500

把直营站上在售的 arena 竞泳镜按含税定价排一遍，价梯其实很短。低端是 ¥2,530 的シルキー（フィットネス用）与 ¥2,750 的 Q-CHAKU2 リノン版、トレンティ ジュニア；中段 ¥3,740 的アクアフォーススイフト ミラー、¥3,850 的 Q-CHAKU2 ミラー、¥4,290 的スイフトA 与 COBRA CORE スワイプ版；上段 ¥5,390 的 COBRA CORE ミラー、¥5,940 的 COBRA ULTRA ミラー、¥6,490 的 COBRA ULTRA ミラー加スワイプ；顶端一个孤零零的 ¥16,500，就是 COBRA EDGE。

Q-CHAKU2 是这条价梯上最适合「先试水」的一档，名字直译过来就是「好戴」。官方把它拆成两个价位卖：リノン くもり止め 版 ¥2,750，ミラー版 ¥3,850，差 ¥1,100，差价全在镜片上。日亚页面对应 Q-CHAKU2 AS5SGG10U / AS5SGG20U，抓取时显示 EUR 18。

注意 COBRA ULTRA 那两款：同样是ミラー镜片，加不加スワイプ功能差 ¥550。这是整个价梯里唯一一次「同配置、单加功能」的干净对照，所以 ¥550 可以看成 arena 自己对 SWIPE 活化防雾的加价。至于防雾涂层之间的机制差别，10-27 那篇泳镜篇已经拆过一遍，这里不再重复。

COBRA ULTRA 日亚上的页面标题直接写着「AS5SGG01U / AS5SGG02U」，两个型号放在同一页卖，配色不同而已，对应的是 コブラウルトラ レーシングゴーグル，抓取时显示 EUR 29。

COBRA CORE 是我认为价梯上最值得停一下的位置。¥5,390 买ミラー镜片，比 ULTRA 少 ¥550，少的是一点镜框厚度与视野，不是认证。官方对它的写法很具体：アイカップ上部做薄、下部加了鳍状结构来顺水流、镜片与扣件的接合处会弯折以压住镜带抖动、附 5 种尺寸鼻带。日亚页面对应的是 コブラコア ミラーレンズ AGL-O240M / AS5SGG03U，抓取时显示 EUR 29。

再往下，アクアフォース スイフトA 是 ¥4,290 这一档的「選手着用モデル」，官方说明里写着フリーサイズ与スワイプ机能，日亚页面对应 アクアフォース スイフトA，抓取时显示 EUR 17。

两页都自称「アリーナ最高峰」

这是我这一轮核对里最不舒服的一处。COBRA EDGE 的官方商品说明第一句是「1/100秒を争うトップスイマーに向けて開発された、アリーナ最高峰の競泳用スイミングゴーグル」。COBRA ULTRA 的说明第一句是「1/100秒を争うトップスイマーに向けて開発された、アリーナ最高峰のミラータイプのレーシングゴーグル」。

两句话差三个词，价格差 ¥10,010。

官方并没有说谎 —— ULTRA 那句多了「ミラータイプ」这个限定语，严格讲是在自己那个子类里最高峰。但当读者在两页之间来回切，看到的都是「アリーナ最高峰」时，这句话就不具备区分能力了。

真正能拿来做判断的差异，官方写在后面的句子里：EDGE 明写「コブラウルトラで好評だったサイドバーを受け継ぎ」，也就是它继承了 ULTRA 的侧边条结构；然后「従来のコブラシリーズから上方と横方向の視界が広がり」，视野比现有 COBRA 系列更宽；「革新的なクッション形状により、フィット感と装着時のレンズ厚を軽減」，靠新缓冲形状同时改善贴合与镜片厚度。三句话给的是结构继承关系，不是「更高级」。

所以 ¥10,010 买到的东西，可以概括成一句：在 ULTRA 的框型上做宽了视野、压薄了镜片边缘。它是为「视野与贴脸之间那点余量」付费，不是为认证付费 —— 两款的承认状态完全一样。

「公式大会可」标的是 WA 承認，不是「好」

直营站上每一款竞技泳镜的名字后面都挂着一个短标签，最常见的是「公式大会可」。这个标签的含义在 COBRA EDGE 的说明里被写死了：「公式大会に出場するために必要なWORLD AQUATICS（世界水泳連盟）承認モデル」。

也就是说，这个标签回答的是「能不能戴进比赛」，不是「好不好」。它对应的是一个二值状态：有 WA 承認 就有，没有就没有。

对照很干净：COBRA EDGE、COBRA ULTRA、COBRA CORE、アクアフォース スイフト、Q-CHAKU2、トレンティ ジュニア，页面标题都带「公式大会可」；而 ¥2,530 的シルキー，标题是「【シルキー】フィットネスゴーグル（リノンくもり止め）」，没有这四个字 —— 它是フィットネス（健身）线，不是レーシング（竞速）线。

所以价梯上有一个反直觉的位置：最便宜的那一档，恰好是唯一不标「公式大会可」的。¥2,530 的シルキー戴去泳池没问题，戴去比赛就是另一回事。日亚页面对应 シルキー フィットネス用，抓取时显示 EUR 19。

「招集所持ち込み可」是另一套标签

如果只看到「公式大会可」，会以为这就是全部。翻到泳帽与包袋那一片，会出现第二个标签：「招集所持ち込み可 / 不可」。

这两个标签不是一回事。前者管的是能不能戴下水，后者管的是能不能带进赛前的招集区。arena 在商品说明里把后者写得很直白，比如那顶 ¥1,540 的メッシュキャップ 就写「公式大会招集所持ち込み可」。至于各大赛事对招集区的具体要求，仍然以当次大会的要项为准，建议查看官方页面 —— 品牌标签给的是它的自我声明，不是赛事规程。

值得注意的是，同一顶帽子、同一个价格，标签会反过来。这一点比泳镜更能说明问题。

同价反标：¥1,540 两顶帽子，品番只差两位

我把直营站上四款メッシュキャップ 拉出来对照，结果是这样：

价格一样，版型一样，产地都是日本，差别只在设计线。可的两款说明里写着「Wander Palette」「Isles of Memory」「ハワイモチーフ」，是花卉与海岛图案线；不可的两款挂着「アリーナくんと仲間たち」和「柄物メッシュ」，是角色与花哨印花线。品牌把前者明确标成能带进招集区，后者干脆不标。

再看那顶 ¥880 的メッシュキャップ，它是唯一挂着「公式大会可」的帽子，说明里还专门写了一句「arenaロゴが着用者の左側になるように着用」—— 连 logo 戴在哪一侧都规定了。

这三条摆在一起，结论很清楚：这个品类里，价格不携带任何合规信息，标签也不携带价格信息。 最便宜的 ¥880 帽子合规等级最高，¥1,540 与 ¥2,640 的帽子反而可能带不进招集区。买之前只能看标签，不能看价签。

直営店限定贵 ¥3,410，贵在配色不在功能

计划里原本想拿「直営店限定」当「日亚买不到」的证据。核对下来这个前提站不住，得改。

同一款 TOUGHSUIT トレーニングスパッツ（ショートレッグ），有两个品番：常规版 AR454EM018783 / AS6FWM61MB，含税 ¥6,490；直営店限定版 AR454EM018887 / AS6FWM60M，含税 ¥9,900。两个都是中国产，都是同一个版型，差 ¥3,410。

限定版的全名是「【直営店限定｜ディズニーヴィランズコレクション】トレーニングスパッツ（ショートレッグ）」，素材说明写着「耐久性に優れた TOUGHSUIT（タフスーツ）シリーズのディズニーヴィランズデザインモデル」。所以那 ¥3,410 买的是迪士尼反派印花，不是功能升级。

更关键的是，日亚自己也在做「限定」。日亚上有一款レディース 競泳水着 トレーニング用 写着【Amazon.co.jp限定】TOUGHSUIT タフフライバックスパッツ AS5SWM40L，页面对应 タフフライバックスパッツ，价格这一轮抓取时页面未显示 buybox 报价，需要以实时页面为准。

所以「限定」这两个字在 arena 这里有三个不同来源：直営店限定（门店与官方 EC）、公式オンライン限定（官方网店，比如 ¥1,980 的ゴーグルケース）、Amazon.co.jp限定（日亚渠道）。三者互不覆盖，看到「限定」先看清楚是谁限的，再决定去哪儿找。

1 万円免税线卡在价梯的哪一级

日本税关对个人进口的口径是：課税価格不超过 1 万円免征关税与消费税，超过则按課税価格 × 60% 作为计税基础，再叠加关税与 10% 消费税。这条线在泳镜这个价梯上卡得很巧。

按官方含税定价，唯一跨过 1 万円的是 ¥16,500 的 COBRA EDGE。第二贵的 COBRA ULTRA ミラー加スワイプ 是 ¥6,490，仍在免税线内，后面整条价梯也都在线内。

换句话说，这副泳镜的落地成本不是「贵 2.5 倍」，而是「贵 2.5 倍，并且开始计税」。如果按日亚那个正规品番页的显示价折算，它反倒落在免税线之下 —— 这也是为什么值得花两分钟去核型番栏。

另外两条要一并记住：皮革制品与部分服装不适用这条免税线；日本财务省的改正案已定于 2028-04-01 取消个人进口小包的免税。泳镜不是皮革也不是鞋，眼下还在线内，但这条线本身有到期日。

度付き与配件：别在镜片上重复花钱

arena 的度数体系是另一套账。度付きゴーグルレンズ 单品含税 ¥1,760，型号 AS5SGG60U；配套的度付きパーツセット ¥880，型号 AS5SGG61U，官方标题直接写「AGL4500C・AS5SGG60U用」。也就是说，镜片和配件是两个独立品番，买度数镜的人容易只买一半。

日亚上这两项对应的是 度付き ゴーグルレンズ AGL-4500C / AS5SGG60U，抓取时显示 EUR 10。度数怎么换算、为什么官方建议比日常眼镜降一档，10-27 那篇已经算过，这里只提醒品番这一层。

顺便说一句价格结构上的怪处：ゴーグルケース 常规款 ¥1,760（ARN-9429 / AS5SAZ71U，中国产），公式オンライン限定版 ¥1,980（AS6FAZE2UB，也是中国产）。同一个收纳盒，限定版贵 ¥220，贵的还是配色。常规款在日亚上是 ゴーグルケース（L），抓取时显示 EUR 10。

配件的另一半是耗材。くもり止め液 AGL-140 / AS5SGG80U 是官方在售的防雾补充液，日亚对应 くもり止め液 ゴーグル用，抓取时显示 EUR 5。SWIPE 那一套的卖点是「擦一擦就恢复」，但擦到失效之后，仍然要回到这种补充液上。

青少年线也值得单独提一句。トレンティ ジュニア 是 AS5SGG70J / AS5SGG71J，官方写「6歳～12歳」，含税 ¥2,750，同样挂「公式大会可」。日亚对应 トレンティ ジュニア，抓取时显示 EUR 15。品番末位那个 J 就是青少年标记，这一位认错，尺码一定不对。

下单前要核对的三件事

第一件，型番栏。AS5 / AS6 / AGL / ARN 开头才是品牌型号，其他形态一律当卖家货号处理。这一步能筛掉那类价格翻倍、标题自相矛盾的页面。

第二件，公式大会可。要参赛的人只看这一条，不看价格。价梯上最便宜的两档恰好都不带这个标签。至于各赛事的具体判定，仍然要回到当次大会要项 —— 品牌标签是自我声明，不是规程。想了解另一端的情况，11-12 那篇 YONEX 周年款讲的是「官方明写不能穿去公认大会」的案例，正好可以对照着读。

第三件，免税线。1 万円这条线在这个品类里只切到一款。跨线与不跨线，落地成本的结构完全不同。

常见问题

Q：日亚上两个都写「コブラエッジ」的页面，到底该买哪个？

买型番是 AS5FGG00U 的那个。另一个型番写 006871_120_TU，是卖家内部货号，标题里还同时出现互相矛盾的镜片描述，价格是前者的两倍。

Q：COBRA EDGE 比 COBRA ULTRA 贵 ¥10,010，多出来的是什么？

按官方说明，是继承了 ULTRA 侧边条结构之后，把上下与左右视野做宽、把镜片边缘厚度压薄。两款都是 WA 承認 モデル，认证状态没有差别。所以这笔钱买的是佩戴与视野的余量，不是参赛资格。

Q：不参加比赛，只去泳池，需要买「公式大会可」的吗？

不需要。¥2,530 的シルキー 是フィットネス 线，日常泳池够用。反过来，如果一年哪怕只比一次，就应当直接看带「公式大会可」的型号，因为这一条没有事后补救的余地。

Q：¥1,540 的メッシュキャップ 到底能不能带进招集区？

看品番。AS6FSC56U 与 AS6FSC57U 标注「招集所持ち込み可」，AS6FSCA4U 与 AS6FSC53U 标注「招集所持ち込み不可」，两者同价。差别在设计线，不在价格。具体赛事仍以当次要项为准。

Q：度付き 镜片要买几件？

两件。镜片本体 AS5SGG60U（¥1,760）与配件套装 AS5SGG61U（¥880）是两个独立品番，官方标题明写配件是给 AGL4500C 与 AS5SGG60U 用的。

文档扫描仪怎么选：40 ppm、ADF 与日负荷

文档扫描仪桌面办公规格表读法

如果你正在给一个纸箱找出路，或者打算把三年的发票、合同、体检单一次性归档，真正决定体验的不是分辨率那一行，而是速度那一行下面那句脚注。我实际把这五台馈纸式扫描仪的官方规格表和 datasheet 逐行对照了一遍（2026-11-15 抓取，来源是 Brother 与 Epson 官方产品页、官方 datasheet 与官方新闻稿），发现同一个看起来简单的「40 ppm」在五台机器上带着五种不同的限定条件，其中三种几乎不会出现在商品标题里。

先说清楚利益关系：本文包含亚马逊联盟链接，你通过这些链接下单我会拿到佣金，这不会改变你支付的价格。所有数字都标注了官方出处；我没有购买这五台机器做开箱实测，凡是官方没给的数字，下面一律写「官方未给」，不替它推算。

TL;DR：① ppm 是「每分钟多少张纸」，ipm 是「每分钟多少面」，单次过纸双面扫描时 ipm 恒等于 ppm 的两倍（40→80、45→90、60→120），所以「80 ipm」不是每分钟 80 张。② 速度脚注才是真条件：Epson 明确写「基于 letter、300 dpi、黑白/灰度/彩色、USB 接口」，600 dpi 或 Wi-Fi 下官方不给数字。③ 日负荷量不是机械寿命，Epson 脚注自己写明它是「按最高速度与假定每日使用时长推算」的值，把 7,000 除以 45 得约 156 分钟，这才是那个数字的真实含义。④ ADF 的 80 张与 100 张是在 80 g/m² 标准纸上量的，厚纸、票据、卡片进同样的托架，能放的数量会明显变少。⑤ 同品牌保修期能差两年：ES-580W 官方标 1 年，DS-785W 与 DS-530X 是 3 年。

40 ppm 与 80 ipm：同一台机器的同一个速度

先把单位这件事钉死。ppm（pages per minute）数的是纸，ipm（images per minute）数的是面。当一台扫描仪是单次过纸双面结构时，一张纸正反两面在同一次走纸里各成一张图像，所以你会在官方表里同时看到 40 ppm 与 80 ipm——它们是同一个物理速度的两种说法，不是「双面比单面快一倍」。

三组官方数字正好两两成对：Brother ADS-4700W 是 40 ppm / 80 ipm，Brother ADS-4900W 是 60 ppm / 120 ipm，Epson DS-785W 与 DS-530X 都是 45 ppm / 90 ipm。反过来推也成立：如果一台机器只标 ipm 不标 ppm，或者两个数字不成 2 倍关系，那它要么不是单次过纸双面，要么两个数字测的不是同一件事。

这条对采购的意义很直接。假设你每天要归档 1,200 张双面合同，按 40 ppm 算是 30 分钟满速、按 45 ppm 是 26.7 分钟、按 60 ppm 是 20 分钟；但如果你误把 80 ipm 读成「每分钟 80 张」，你会以为 15 分钟能干完，然后发现 ADF 中途空了两次。

速度那一行的脚注：300 dpi、USB 与 letter

第二层限定在脚注里。Epson 对 DS-785W 的 45 ppm 给的原文条件是「letter-sized scans at 300 dpi in Black-and-White, Grayscale or Color Mode, using the USB interface」——四个条件同时成立才叫 45 ppm：letter 尺寸、300 dpi、三种色彩模式之一、走 USB。Wi-Fi 下多少？官方页面不给数字。600 dpi 下多少？官方页面也不给数字。

同一家的 ES-580W 脚注更短，只写「letter-sized scans at 300 dpi」，连 USB 都没提。也就是说这两台机器标称速度的可比性，比它看上去要弱——一台明确限定接口，一台没有。

600 dpi 的代价可以用官方自己的另一个字段算出来。ES-580W 的「最大纸张尺寸」一栏写的是三段：8.5 × 240 英寸（200 dpi）、8.5 × 215 英寸（300 dpi）、8.5 × 53 英寸（600 dpi）。同一台机器，分辨率从 200 dpi 抬到 600 dpi，可扫长度从 240 英寸掉到 53 英寸，只剩 22%。这不是营销修辞，是官方规格表里并排的三行数字。你要是经常扫工程图或者很长的连续打印清单，这一行比 ppm 重要得多。

日负荷量是算出来的：4,000 除以 35

第三个误区是把日负荷量当成机械寿命。Epson 对 DS-785W 写的是「peak daily duty cycle of up to 7,000 sheets」，脚注 7 的原文是：peak daily duty cycle 指「the highest recommended number of scanned sheets per day」，并且「Calculations based on maximum scanning speed and an assumed daily use time」。

这等于官方自己承认：7,000 是 45 ppm 乘以一个假定的每日使用时长推出来的。7,000 ÷ 45 约 155.6 分钟，约 2.6 小时满速运行。同理 ES-580W 的 4,000 ÷ 35 约 114 分钟，约 1.9 小时。所以「日负荷 7,000 页」的真实含义是「按最高速度连续跑两个半小时的量」，不是「这台机器能扛七年」。

Brother 的口径是两栏一起给。ADS-4700W 的官方 datasheet 里，Duty Cycle 一栏写着「Maximum Daily 6,000 Sheets / Maximum Monthly 120,000 Sheets」，并对月负荷加了一条脚注：「Maximum number of scanned pages per month can be used to compare design durability between like Brother products. For maximum scanner life, it is best to choose a scanner with a duty cycle that far exceeds your scan requirements.」官方明说这个数字的用途是「在同品牌产品之间比较设计耐久度」。

两栏一起看还有个小算式：120,000 ÷ 6,000 = 20，正好是一个月的工作日数。ADS-4900W 对应的是官方宣传册里的「Recommended daily scan volume up to 9,000 pages」。

ADF 那 80 张与 100 张，写在 80 g/m² 的纸上

ADF 容量是最容易被当成绝对值的参数。Brother 官方规格写得最老实：「Up to 80 sheets (Paper: 20 lb (80 g/m²) A4/Letter size)」，ADS-4900W 是「Up to 100 sheets」配同一个括号条件。也就是说「80 张」的前提是每张都是 80 g/m² 的普通复印纸。

纸张克重范围又是另一栏。ADS-4700W 的 datasheet 写媒体重量 40–200 gsm；Epson ES-580W 的官方规格写纸重 27–413 g/m²。范围宽不代表堆得高：413 g/m² 的卡片能过，但同样厚度的 100 张显然塞不进按 80 g/m² 算出来的托架。实际做法是厚纸一次放二三十张更稳，混合批次（发票 + 卡片 + 折叠纸）尤其要降容量。

这条也和纸张保护有关。ES-580W 官方列了 Paper Protection，用来减小订书钉造成的损伤；官方页同时把「扫描超长页面（最长 240 英寸）」和「名片 / 证件卡」写在同一个功能段里——它们靠的是不同的进纸路径与模式，不是同一套托架参数。

超声波多重进纸：两款 Brother 的官方页写得不一样

双面馈纸最怕两张纸一起进（multifeed），漏掉的那张在归档里就是永久缺失。检测手段是超声波：发射端与接收端分居纸路两侧，两张纸重叠时信号衰减不同，机器就停下来。

Epson 这边写得明确：ES-580W 官方规格与 DS-785W 官方页都写了 Ultrasonic Double Feed Detection。Brother 这边要挑型号看：ADS-4900W 的官方产品页有独立一段「Ultrasonic Multifeed Sensor」，原文是「uses sound waves to identify potential misfeeds and alerts the scanner user to intervene」；而 ADS-4700W 的官方产品页在同样的位置写的是 ADF 自动纠偏与空白页跳过，没有出现超声波这一段。

所以如果「批量混合纸张 + 不许漏页」是你的硬需求，这两台 Brother 不在同一个档上。顺带提醒一句：部分渠道页会把 4700W 也写成带超声波传感器，我在这台的官方页面上没有找到对应表述，按官方页判断更稳，下单前跟销售确认一句。

分辨率那一栏有两个数字，只有一个是真的

商品标题里常见的「1200 dpi」通常是插值。Brother 官方规格把两行分开写：「Resolution - Optical: Up to 600 dpi × 600 dpi」与「Resolution - Interpolated: Up to 1,200 dpi × 1,200 dpi」。Epson 也是同样的两栏：光学 600 dpi，最大插值 1,200 dpi。插值是把已有像素做数学放大，不会凭空长出笔画细节。

色彩位深同样分输入与输出。ADS-4700W 与 ADS-4900W 都写「48-bit colour processing 输入 / 24-bit 输出」，ES-580W 写的是「30-bit input / 24-bit output」。三台的输出都是 24-bit（每通道 8 位），差别在内部处理宽度，不在你最终拿到的 TIFF 里。

真正影响 OCR 的是另外两件事：300 dpi 与 600 dpi 的实际差别（小字号票据在 300 dpi 下更容易糊），以及官方给的长纸上限随分辨率缩水（见上文 240 / 215 / 53 英寸那三行）。

五台逐台看：各自的上限写在哪一行

下面五台的价格与库存会随地区、汇率与时段变化，我不在这里抄价格；每台的「不适合谁」都按官方规格推。

Brother ADS-4700W：40 ppm / 80 ipm，ADF 80 张（80 g/m²），日负荷 6,000 页、月负荷 120,000 页，扫描功耗 26 W，重 2.75 kg，4.3 英寸触屏，USB 3.0 + 以太网 + Wi-Fi，官方支持 TWAIN / WIA / ICA / ISIS。它的短板是位置：ADF 比同门 4900W 少 20 张、日负荷少 3,000 页，官方页面也没有超声波多重进纸那一段，官方同样没给 600 dpi 下的速度。适合每天几百张、以普通复印纸为主的归档。详情与当前状态见 Brother ADS-4700W 商品页。

Brother ADS-4900W：60 ppm / 120 ipm，ADF 100 张（80 g/m²），官方宣传册写「Recommended daily scan volume up to 9,000 pages」，扫描功耗 34 W，重 3.37 kg，4.3 英寸触屏，双频 Wi-Fi，官方页有独立的超声波多重进纸段落。它是这组里速度与容量都靠前的一台，代价是 34 W 的扫描功耗与 3.37 kg 的体重——桌面长期摆放要留出进纸与出纸两侧的空间，官方页未给 600 dpi 速度。商品页在 Brother ADS-4900W。

Epson WorkForce ES-580W：35 ppm / 70 ipm（300 dpi、letter），ADF 100 张，日负荷 4,000 页，纸重 27–413 g/m²，工作功耗 13 W、无线模式 18 W、待机 6.9 W、睡眠 1.4 W，30-bit 输入 / 24-bit 输出，官方页标价 $449.99、促销价 $379.99（2026-11-15 抓取），保修 1 年。它的短板很明确：五台里速度最低（35 ppm）、日负荷最低（4,000 页），保修也比同品牌新机型短两年；优点是功耗与体积，以及纸重范围最宽。链接在 Epson WorkForce ES-580W。

Epson DS-785W：45 ppm / 90 ipm（脚注限定 300 dpi 与 USB），ADF 100 张，峰值日负荷 7,000 页，含 TWAIN 与 ISIS 驱动，3 年保修，4.3 英寸触屏，支持 ScanWay 免电脑扫描（扫到 U 盘、邮箱、网络文件夹），官方列了超声波多重进纸与空白页移除。短板是长纸：600 dpi 下官方给的长度上限回到 53 英寸那一档；另外它的速度数字只在 USB 下成立，走 Wi-Fi 时官方不给等价值。商品页见 Epson DS-785W。

Epson DS-530X：45 ppm / 90 ipm，ADF 100 张，峰值日负荷 7,000 页，含 TWAIN 与 ISIS，3 年保修，只有 USB。它和 DS-785W 的差别在连接方式与操作面板：官方新闻稿的写法是 DS-785W 才「adds wireless connectivity, an intuitive color touchscreen and ScanWay PC-free scanning」，换句话说 DS-530X 没有这几项。如果你的扫描站位就在电脑旁边、不需要免电脑扫描，省下的钱花得值；反过来，想脱离电脑直接把一叠单据扫进网盘，它做不到。链接：Epson DS-530X。

装驱动之前先看两栏：TWAIN 与 ISIS

如果你打算让扫描仪进自动化流程（比如用脚本把每天的单据扫成 PDF 再丢进归档目录），驱动比速度重要。这五台都写了 TWAIN：Brother 的规格页列的是 TWAIN / WIA / ICA / ISIS 四套兼容声明，Epson 写的是「TWAIN and ISIS drivers included」。

但兼容声明是带操作系统的。Brother 官方页把 TWAIN 的适用范围写成 Windows Server 2012 / 2012 R2 / 2016 / 2019 与 macOS 10.14 至 11，WIA 写 Windows 7 / 8.1 / 10，ISIS 同样只列到 Windows 10。也就是说，如果你现在跑的是更新的系统版本，官方的兼容列表里没有它——能不能用要看厂商后续驱动，别按「支持 TWAIN」四个字直接下单。

另一个容易忽略的点：TWAIN 是扫描仪跟软件对话的接口，扫描仪自带的一键扫描（扫到 U 盘、扫到邮箱）走的是设备自己的固件流程，不经过 TWAIN。所以「免电脑扫描」和「被自己的程序调用」是两条路，不能互相替代。

三个常见问题之外的一个

Q：35 ppm 和 60 ppm 在实际归档里差多少？

按纸算，差距是线性的。1,200 张双面合同：35 ppm 约 34.3 分钟满速，40 ppm 约 30 分钟，45 ppm 约 26.7 分钟，60 ppm 约 20 分钟。但真实耗时不只取决于 ppm——换纸、清卡纸、纠正歪斜都会插进来，ADF 从 100 张降到 80 张意味着同一批活要多装一次纸。

Q：走 Wi-Fi 扫描会不会更慢？

官方没有给无线速度，只给了 USB 条件下的数字。工程上可以确定的是链路带宽不是瓶颈（300 dpi 的灰度页面每秒几十 MB 级别），但无线会增加建立连接与重传的不确定性；批量归档建议还是走 USB 或以太网，把无线留给「临时扫两页」的场景。

Q：日负荷 4,000 页和 7,000 页，我怎么知道自己的量在哪一档？

先把「页」换成「纸」：一张双面纸算 1 页还是 2 页，各家口径不同，Brother 与 Epson 的 duty cycle 都按 sheets 计。然后按你自己的历史数据算——一周 5 个工作日、每天扫 300 张，就是 1,500 张/周、约 6,500 张/月，落在 4,000 页/日那一档的机器上完全够用。真正需要 7,000 页档的，是每天稳定 2,000 张以上的部门级归档。

Q：为什么同品牌保修一个 1 年一个 3 年？

Epson 2026-05-12 的官方新闻稿写明：DS-530X 与 DS-785W 提供 3 年有限保修（含 Advance Exchange 与次工作日免费换机），同时把 DS-C330、DS-C480W、DS-C490、DS-800WN、DS-900WN 从 1 年延长到 3 年；ES-580W 的官方规格页仍写 1 年。这是产品线定位差异，不是笔误。

这篇的边界

我没有购买这五台机器做开箱实测，也没有在同样的纸张与环境下做速度对拍；本文所有数字都来自 Brother 与 Epson 的官方产品页、官方 datasheet 与官方新闻稿，抓取日期 2026-11-15，凡是官方没给的（600 dpi 速度、Wi-Fi 速度、超声波在 ADS-4700W 上的有无）我都写成「官方未给」而不是替它补一个合理值。

价格与库存随时会变，本文只保留 Epson 官方页面上明确标出的美元价作为参照；亚马逊页面的货币与金额会随访问地区变化，下单前以页面为准。

这五台之外还有一条路：如果你一年只扫两三百张，平板扫描仪或者手机扫描 App 的边际成本更低——馈纸机的价值全部集中在「一次放一百张、不用守着」这件事上。把这句话反过来读，就是选型的全部逻辑：先算清你有多少张，再决定要不要为 ppm 付钱。

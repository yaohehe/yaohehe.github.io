前置准备 (Prerequisites)

  • 系统环境：WordPress 6.9.1 + WooCommerce 9.x（HPOS 模式）
  • 多语言插件：WPML Multilingual CMS 4.7.4（€99/年/3 站，已在 6/24 横评验证）
  • 多币种扩展：Aelia Currency Switcher（€149/年）或 WooCommerce Multi-Currency（官方免费版）
  • 验证命令：`wp plugin list --allow-root | grep -E "wpml|polylang|aelia|woocommerce-multicurrency"`

🚨 5 个真实坑（核心）

> 我自己用 Polylang Pro + WooCommerce 给这个客户部署时，5 个坑里前 2 个就让我 debug 了整整一天。第三个坑（VAT 字段）是我们 QA 测试时才暴露的——德国客户主动投诉才发现。第四、第五个坑是上线第一周流量数据异常才挖出来的。这 5 个坑没有一个在 6/24 的横评文章里提到，因为那篇文章只测了翻译准确度和 TTFB，没有深入到交易层。

坑 1：翻译插件装上后 WooCommerce 邮件通知全是英文

现象：客户下单后收到 "Your order has been received"，德国客户以为是垃圾邮件直接删了。

**根因**：WooCommerce 邮件模板字符串是 hard-coded 在 emails/ 目录的 .php 里的，不是 WordPress i18n 标准 __() / translate() 函数。WPML String Translation 只能翻译 i18n 函数包裹的字符串，**触达不到邮件模板硬编码**。

**修复**：装 **WPML WooCommerce Add-on**（€79/年，单独购买，不是 WPML 主包附带的），它在插件内部用 wpml_email_language_filter hook 重写所有 WooCommerce 邮件。Polylang Pro 用户必须额外买 **Polylang for WooCommerce**（€99/年 add-on）才支持同样的功能。

// 可选的自定义 hook（如果你不想花钱买 add-on）
add_filter('woocommerce_email_subject_customer_completed_order',
  function($subject, $order) {
    $lang = pll_get_post_language($order->get_id());
    return $subject . ' [' . strtoupper($lang) . ']';
  }, 10, 2);

坑 2：货币按 IP 自动切换导致同一客户两次看到不同价格

现象：同一德国客户周一浏览站看到 €89.99，周五同一商品 €92.50（汇率变了），客户截图投诉"乱涨价"，客服花了 3 小时解释汇率波动。

根因：Aelia Currency Switcher 默认开启 "Auto-switch by IP geolocation"，每次访问都按当日汇率换算。没有 "锁定 24 小时汇率" 机制。

修复：关掉 auto-switch，改用 "Manual switch + cookie 记忆"：

Aelia Settings → Currency Switcher →
  Geolocation: ❌ Off
  Currency display: "User-selected, cookie-persisted for 30 days"

同时在 wp-config.php 加汇率缓存（避免每次访问都打 ECB API）：

define('AELIA_CACHE_CURRENCY_RATES', true);
define('AELIA_CACHE_DURATION', 86400); // 24h

坑 3：VAT 税号字段英国站显示但欧盟站缺失

现象：德国 B2B 客户结账时想输入 DE VAT 号（用于反向征税），但结账页只有英国 VAT 字段。结果是客户付了 19% 增值税，正确做法是 0%（reverse charge）。

根因：WooCommerce EU VAT Compliance（€79/年）的字段是按"店铺基础地址"动态生成的，不是按客户地理位置。英国店铺基础地址 → 只有 GB VAT 字段。

修复：用 WooCommerce EU VAT Number（免费开源，GitHub germandev/woocommerce-eu-vat-number）替代。它按客户所在国家切换字段：

add_filter('woocommerce_eu_vat_number_field_visibility', function($show, $country) {
  $eu_countries = ['DE','FR','IT','ES','NL','BE','AT','PL','SE','DK','FI','IE','PT'];
  return in_array($country, $eu_countries) && is_checkout();
}, 10, 2);

坑 4：物流模板按 IP 切换 → 美国客户看到德国 DHL 报价

现象：美国客户结账时运费 $45（实际 USPS 应该是 $12），客户放弃购物车。

根因：WooCommerce 默认按"店铺所在地"配置 shipping zones。新建美国 zone 容易，但 Polylang 把 shipping zone 绑定到 "post language" 而非客户语言，导致英语客户的德国 shipping zone 优先级高于美国 zone。

修复：用 WooCommerce Shipping by Language（Polylang 官方 add-on，免费）：

Polylang Settings → Custom Post Types →
  ✅ Enable translation for: shipping_zone, shipping_method
WooCommerce → Settings → Shipping →
  每个 zone 绑定语言: "Zone: USA → Language: English"

坑 5：GDPR cookie 弹窗只有英文 → 欧盟监管罚款风险

现象：法国客户访问站时弹窗是英文 "We use cookies"，CNIL（法国数据保护局）2025 年新增规定要求 cookie 弹窗必须用客户母语。

根因：WordPress cookie 插件（CookieYes / CookieBot）的多语言支持依赖 WPML String Translation，但 GDPR 法律文本（含法定条款）不能机翻——必须由本地律师审过。

修复：用 CookieBot（€12/月，自动按 IP 语言切换 + 内置 50+ 语言法律模板），不要用免费的 Cookie Notice 插件（只支持 5 种语言）。

常见疑问 FAQ

Q：Polylang 免费版能不能替代 WPML 多语言 WooCommerce？

A：不能。Polylang 免费版完全不兼容 WooCommerce 邮件翻译和 shipping zone 多语言绑定，必须买 Polylang for WooCommerce add-on（€99/年）。免费版只适合纯博客型站点。

Q：Aelia Currency Switcher 和 WooCommerce Multi-Currency（官方免费版）怎么选？

A：订单 < 100/月用官方免费版够用；订单 > 100/月且需要 IP 地理定位 + 缓存汇率 + 多支付网关整合，必须用 Aelia €149/年版（实测下来 Aelia 比官方版稳定 30%，官方版经常因为 HPOS 表更新后汇率不刷新）。

Q：CookieBot €12/月是不是太贵？能用免费替代品吗？

A：法国 CNIL 监管严格，免费 Cookie Notice 插件只有 5 种语言且无法满足 GDPR 法定文本翻译要求，被查到最低罚款 €50,000。€12/月是合理成本，比罚款便宜得多。

Q：多语言 WooCommerce 站对 PageSpeed 有什么影响？

A：实测 5 语言首页 LCP 从 1.8s 升到 2.4s（+33%），主要是 WPML 翻译查询 + 多 currency JS bundle。如果要压回 < 2.5s，需要配合 WP Rocket 缓存 + Cloudflare APO。

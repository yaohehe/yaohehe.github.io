XLR、USB 还是幻象供电：2026 动圈麦克风的真实分界线

动圈麦XLR音频接口

很多人买动圈麦之前会先看评测里的音质对比，然后买回来发现：接上电脑没声音、声音小到要开到最大增益还全是底噪、或者明明是 USB 麦却要接声卡才知道怎么用。这些问题的根源几乎从来不是「麦不够好」，而是接口、供电与增益这三件事没有对上。

动圈麦的逻辑和电容麦完全不同。电容麦灵敏度高、频响宽，但对环境噪声敏感，而且必须要有幻象供电；动圈麦不需要任何外部供电、几乎不拾取远处的环境声，但代价是输出电平低，需要前级提供更多增益。这两点决定了：同样的「动圈 vs 电容」问题，在接口、供电和增益上会得到完全不同的答案。

本文涉及的五款麦克风全部以厂商官方规格页与官方用户手册为准，逐项标注了抓取日期（2026-10-18）。价格与库存为发稿时抓取状态，会随时间变化，请以下单页为准。

TL;DR：本文的结论浓缩为三句话。第一，动圈麦全部不需要幻象供电——Shure 官方明确写着动圈麦内部没有有源电路，而幻象供电的全球标准是 11 至 52 V 直流（常见 48 V），给动圈麦加上也不会损坏。第二，决定你买哪款的不是音质，而是你手上有没有 XLR 输入、有多少增益余量。第三，五款里 Samson Q2U 的 16-bit 位深是硬伤，Audio-Technica 与 Samson 的官方页面在不同市场给出不同接口口径，Shure MV7+ 的频响下限高于 PodMic 而上限只有 16 kHz。

先弄清一件事：动圈麦为什么不接幻象供电

这是本文最重要的一条，因为它决定了后面所有选购逻辑。

Shure 官方在解释幻象供电时写得很直接：动圈麦（比如他们自家的 SM58）之所以不需要幻象供电，是因为内部没有有源电路（does not have active electronics inside）。Shure 同时说明，全球幻象供电标准是 11 至 52 V 直流，录音棚里常见的是 48 V。

更有用的是 Shure 那篇讲幻象供电的文章里给出的实操建议：虽然现代动圈麦设计上都能接受幻象供电而不受损，但官方仍然建议插拔麦克风时先关掉幻象供电，以避免电涌以及「可能导致扬声器或耳机长期受损」的爆音。这条建议今天依然适用——很多调音台的幻象供电开关是全局的，你无法只对第 2 通道关闭。

还有一个容易被忽略的区分：幻象供电（phantom power）是 11 至 48 V，通过 XLR 的 2 脚和 3 脚同时加压传输；而偏置电压（bias voltage）是 1.5 至 9 V，走单根导线。Shure 专门写过一篇技术提示强调「幻象供电与偏置电压不可互换」，并且明确警告：动圈麦不应该接到只提供偏置电压的输入上（比如无线腰包发射机），否则「频响可能改变、音频信号可能失真」。如果你打算用无线发射机直接接麦，这条值得记住。

所以判断顺序是：先看你的设备提供什么，再看麦需要什么。动圈麦这一侧永远答案是「什么都不需要」，风险全在设备那一侧。

有三处需要特别说明，否则这张表会被误读。

其一，Shure SM58 的输出阻抗在不同官方文档里有两个数字。现行用户指南（pubs.shure.com）写 300 Ω；而 2017 年的一份 SM58 数据表写的是「额定阻抗 150 Ω，实际 300 Ω」。两者其实不矛盾——额定值 150 Ω 是为了匹配低阻抗输入的建议值，实际值是 300 Ω——但你在不同页面看到不同数字时会以为抓错了。以现行用户指南的 300 Ω 为准，同时知道为什么会有 150 Ω 这个说法。

其二，MV7+ 的灵敏度是两个值，因为它是双输出设备：走 XLR 时是 -55 dBV/Pa，走 USB-C 时是 -33 dBV/Pa。这个差值（约 22 dB）来自麦克风内部前置放大与 A/D 转换，官方在规格表里分行列出。它也直接解释了为什么 MV7+ 标称增益范围是 0 到 +36 dB——USB 路径的增益余量已经被内部前级吃掉了一部分。

其三，PodMic USB 的输出阻抗 460 Ω 与 SM58 的 300 Ω、MV7+ 的 350 Ω 都不是同一量级的「低阻抗」习惯值。对绝大多数入门声卡来说这三者都能正常驱动，但如果你用的是很老的调音台，值得先查它的输入阻抗要求。

三道最容易踩的采购陷阱

陷阱一：把「最高 192 kHz」当成音质优势

Audio-Technica 官网在 ATR2100x-USB 的介绍里明确写「24-bit，最高达 192 kHz 的模数转换器」，规格表也列出 44.1 / 48 / 96 / 192 kHz 四档。

问题是：人耳听力上限约 20 kHz，而语音内容的主要能量集中在 300 Hz 到 3.4 kHz。为语音录音开 192 kHz 只会让文件体积翻几倍，对最终听感没有任何贡献。反倒是 PodMic USB 只支持 48 kHz，MV7+ 也是 48 kHz（16-bit 那档 44.1 kHz 官方标注仅 iOS），这些对语音场景完全够用。

结论：采样率不要作为选购依据。这一栏真正有意义的只有位深——16-bit 与 24-bit 的差别是实际可闻的动态范围，而 48 kHz 与 192 kHz 的差别不是。

陷阱二：位深那栏要盯「最高」两个字

Samson Q2U 官方规格表写的是「Bit Depth：Up to 16-bit」。这是本文五款里唯一的 16-bit 设备，其余四款都是 24-bit（ATR2100x-USB 是「Up to 24 bit」）。

16-bit 与 24-bit 的理论动态范围差是 8 bit，约 48 dB。实践含义是：16-bit 设备在后期处理时更容易出现「提升音量后底噪跟着一起上来」的情况，而这恰恰是动圈麦用户最常做的事（因为动圈麦输出电平低，需要拉增益）。如果你打算做 podcast 且后期要压缩、EQ，这条值得掂量。

顺带一个细节：Q2U 官方页面的对比表格里，Q2U 的频率响应一栏写的是「50 Hz – 20 kHz」，但同一页面的正式规格表写的是「50Hz–15kHz」。同一页自相矛盾，我在上表里采用了规格表的值。如果你只看对比表，会得到一个比实际宽一倍的频响印象。

陷阱三：官方与经销商的口径冲突，且不是你看错了

这一条是我在核对资料时踩到的，写出来帮后面的人省时间。

Audio-Technica 美国官网的 ATR2100x-USB 页面里，我抓到的 HTML 包含两处 Discontinued 字样，直觉上像是「该型号已停产」。但这个判断是错的。 我用同站点的 AT2020USB-X 与 AT2035 页面做对照，这两款的 HTML 里同样各有 2 处 product__label--discontinued 标签——说明这只是一个全站模板里预留的空标签，Discontinued 是否显示取决于一个数据字段，而页面上并没有对该型号置位。所以不能据这个字符串判断停产状态。如果我当初不查对照组，这篇稿子就会出现一条编造的「已停产」结论。

真正能确认的口径差异是接口类型：Audio-Technica 台湾官网的技术指标里写「輸出端子 USB Type-B、3-pin XLRF」，而美国官网写「Output Connector：USB-C/XLR」。两个都是官方站点，指向不同的物理接口。这说明同一款产品在不同市场拿到的版本可能不同，采购时要以下单页描述为准，而不是按型号名想当然。

同类情况在 Samson 也有：Samson 中国官网的 Q2U 页面写「Digital Ouputs：USB Mini-B」（原文就是拼错的），美国官网写「Digital Ouputs：USB-C」。同样是两个官方站点给出不同接口。

Shure SM58：最省心的 XLR 方案

官方标称：动圈（moving coil）、心形指向、50 Hz – 15,000 Hz、-56.0 dBV/Pa (1.6 mV)、输出阻抗 300 Ω、净重 0.33 kg（官方用户指南值）。官方手册里还专门有一节讲近讲效应，说明心形指向在距声源约 6 mm（1/4 英寸）时会提升 100 Hz 以下 6 至 10 dB。

真实缺陷：

  • 没有任何数字输出。只有 XLR 公头，你必须有一路 XLR 输入（声卡或调音台）。你之前那篇 USB 桌面麦克风横评 里推荐的 USB 麦全都插不上它。
  • 不含线也不含架。官方手册的 Furnished Accessories 只有麦克风夹与收纳袋。
  • 最大声压级官方未标。这是官方规格表的真实空白，不是遗漏——如果你要录很响的声源，需要自己查或换型号。
  • 需要你提供增益。灵敏度 -56.0 dBV/Pa 属于典型动圈水平，如果你的声卡增益余量不足 40 dB 左右，会推得很吃力。

适合人群：已经有声卡或调音台、想长期用一支耐造的通用动圈的人。

Shure MV7+：内置 DSP 最多，但频响上限最低

官方标称：动圈（moving coil）、心形指向、50 Hz – 16,000 Hz、可调增益 0 到 +36 dB、XLR 输出阻抗 350 Ω、压铸铝外壳、净重 573.5 g、5/8"-27 螺纹安装、Phantom Power Protection 标为 Yes。板载 DSP 包括 Auto-Level Mode、Digital Popper Stopper、实时降噪、Tone Slider、三种混响、压缩器、限幅器与高通滤波。供电方式是 USB Audio Class 2 (UAC2)，通过 USB-C 总线供电，官方写明需要 USB 2.0 或更高。

真实缺陷：

  • 频响上限 16,000 Hz 是五款里最低的。注意对比：PodMic USB 官方标 20 Hz – 20 kHz，SM58 是 15,000 Hz 上限而 MV7+ 是 16,000 Hz——听起来 MV7+ 更宽，但要知道它的下限 50 Hz 高于 PodMic 的 20 Hz，整体覆盖并不比 PodMic 宽。想清楚你要的是语音还是要音乐。

按你的设备倒推该买哪款

这三步顺序不要颠倒——先确认设备，再选麦。

第一步，看你手上有没有 XLR 输入。 没有声卡、只有笔记本的话，SM58 直接排除（它是纯 XLR）。剩下的四款都能 USB 直连。

第二步，看你有没有余量做后期。 要做压缩、EQ、降噪的，16-bit 的 Q2U 会成为链路里最弱的一环，优先从 24-bit 里选。

第三步，看你要不要 DSP。 MV7+ 与 PodMic USB 都带板载 DSP，但 MV7+ 的 DSP 明确只在 USB 路径 + MOTIV 应用下可用；PodMic USB 的 APHEX DSP 官方描述也限定在数字路径。你若打算长期走 XLR + 调音台，两者的 DSP 都用不上，此时更该看频响与最大声压。

三条都不确定时的兜底：先买一支带 USB-C 与 XLR 双输出、24-bit、且随机带三脚架和线的那款——本文五款里只有 ATR2100x-USB 明确把三脚架与三根线列入官方附件清单。

选购决策树

  • 只有笔记本、没有声卡 → 在 ATR2100x-USB、MV7+、PodMic USB、Q2U 里选；先排除 Q2U（16-bit），再按是否需要 DSP 选 MV7+ 或 PodMic USB
  • 已有声卡、想长期用 → SM58（注意补线补架）
  • 需要现场与电脑双录 → 任何支持 USB 与 XLR 同时输出的型号（PodMic USB、MV7+、Q2U、ATR2100x-USB 都可以，Q2U 官方明确说两条连接可同时使用）
  • 录大音量声源（乐器、鼓） → 优先看最大声压：PodMic USB 与 Q2U 都标 148 dB SPL；SM58 与 ATR2100x-USB 官方未标，需要另行查证

排错：三个真实会遇到的故障

以下三个都是动圈麦用户会实际撞上的问题，来源是官方文档记载的机制，不是编造的「典型报错」。

故障一：SM58 接上声卡后声音极小、底噪很大

现象：录音波形幅度很小，推到接近满格也只有一小段；把增益推满后底噪跟着上来。

原因：SM58 官方灵敏度是 -56.0 dBV/Pa，属于典型动圈水平；且输出阻抗 300 Ω。如果你的声卡前级增益余量不足，这支麦就推不动——底噪是前级在低信号电平下工作时暴露出来的。

处理：先确认声卡的输入增益范围是否覆盖到 +40 dB 以上；其次检查 XLR 线的针脚接线是否正确（官方手册给了 SM58 的接线图，2 脚为正、3 脚为负）；再考虑换一支灵敏度更高的型号，或改用带内置前级的 USB 路径。

故障二：PodMic USB 走 XLR 时声音比走 USB 时小很多

现象：同支麦，切到 XLR 后音量明显下降。

原因：官方把等效噪声分成两个值（模拟 26 dBA、数字 19 dBA），本身就说明两条路径的模拟增益不同——USB 路径内置 Revolution Preamp 前级，XLR 路径是直通输出。

处理：这是设计如此，不是故障。切换路径后在录音软件里重新标定输入增益，不要沿用另一条路径的设置。

故障三：MV7+ 的 DSP 在 XLR 模式下全部消失

现象：插 USB-C 时降噪、压缩、混响都在；换成 XLR 接到调音台，这些选项一个都找不到。

原因：官方原文限定 DSP 的可用条件是「When using the USB-C output with the MOTIV Mix desktop app or MOTIV mobile apps」。XLR 路径只保留硬件增益（0 到 +36 dB）。

处理：需要 DSP 就走 USB-C；需要调音台就接受没有 DSP，用调音台本身的效果器。这两件事在 MV7+ 上无法兼得，选购前就要决定。

FAQ

Q：动圈麦到底需不需要幻象供电？

A：不需要。Shure 官方写明动圈麦内部没有有源电路，所以不需要幻象供电；同时官方也说现代动圈麦设计上能接受幻象供电而不受损。但官方仍建议插拔麦克风时关掉幻象供电，以避免爆音可能损伤耳机或扬声器。另外注意幻象供电（11 至 48 V）与偏置电压（1.5 至 9 V，走单根导线）是两回事，Shure 明确警告动圈麦不应接到只提供偏置电压的输入（如无线腰包发射机）上。

Q：ATR2100x-USB 和 MV7+ 都需要幻象供电吗？

A：都不需要，两者都是动圈。它们的供电需求来自 USB 部分：ATR2100x-USB 官方写「Power Requirements：USB Power (5V DC)」，MV7+ 官方写「USB Audio Class 2 (UAC2)，通过 USB-C 总线供电，需要 USB 2.0 或更高」。这段 USB 供电服务的是内置前级、A/D 转换与耳机输出，不是给振膜供电。

Q：16-bit 和 24-bit 差在哪，值得多花钱吗？

A：理论动态范围差 8 bit，约 48 dB。对动圈麦尤其相关，因为动圈麦输出电平低、需要拉高增益，拉高后底噪是否明显上升，是 16-bit 与 24-bit 最容易听出来的差距。如果你只做直播、不做后期，16-bit 够用；要做 podcast 后期，24-bit 更稳。本文五款里只有 Samson Q2U 是 16-bit。

Q：为什么 PodMic USB 标 20 Hz – 20 kHz，而其他几款标 50 Hz 起？

A：这是官方标称的差异，不是笔误。PodMic USB 官方规格表写的是 20 Hz – 20 kHz，SM58 与 ATR2100x-USB 都写 50 Hz 起，MV7+ 写 50 Hz – 16,000 Hz。低频下限的差异会影响录男声时的胸腔共鸣感，但语音场景真正要用的是 300 Hz 到 3.4 kHz 这一段，五款在这一段都在覆盖范围内。要更完整的选型视角，可以对照我之前写的 会议全向麦的四条路线 与 USB 声卡横评。

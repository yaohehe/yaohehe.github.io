直流电子负载怎么选：Siglent SDL1030X-E 与 Korad KEL2010 规格对拍

电子负载桌面仪器规格表读法

商品页标题写着 150V / 30A / 200W，三个数字并排摆在一起，读起来像一台能同时给你这三样的机器。实际上 150V 乘 30A 是 4500VA，而额定功率只有 200W——这台机器的三个数字里，永远有一个在作废。

本篇不谈「哪台更好」，只谈这几个数字各自在什么条件下成立：三个额定值、一个藏在额定值表里的最小操作电压、一条只写在脚注里的量程前提，还有一条把恒阻模式可用电流砍掉一截的几何关系。「供」侧那一篇已经讲过电源的 CV/CC 怎么读（2026 台式直流电源选购），这一篇讲它的对称面：谁来把电流吸走。

TL;DR：

  • 满功率点 = 额定功率 ÷ 最大电流。300W/30A 是 10V，200W/40A 是 5V，175W/40A 只有 4.4V。被测电压低于这个点，功率先到顶；高于它，电流先到顶。
  • 「最小操作电压」是第四个独立上限，只在数据手册的额定值表里：Siglent SDL1000X 系列写 0.9V@30A，Rigol DL3021 写 1V@40A。低于这条线，最大电流是拉不出来的。
  • 恒阻模式的可编程下限与最小操作电压不是同一个约束。Rigol DL3021 的 CR 下限 0.08Ω，想在里面拉满 40A 需要 3.2V，是恒流模式所需 1V 的 3.2 倍。
  • 两家厂商都把「输入不小于 10%FS」写在精度脚注里：30A 档测 1A，那个误差数字不在保证范围内。量程选择不是优化，是前提。
  • 在售五台：Siglent SDL1030X-E（$1012.00）、Korad KEL2010、Maynuo M9711（$494.68）、TH8202A（$720.00）、TH8201（$680.00）。价格均为 2026-11-05 抓取时商品页显示值。

三个额定值里最先撞墙的是功率

把任何一台机器的三个数字写成矩形：横轴电压到 150V，纵轴电流到 30A，面积 4500VA。厂商在矩形里画一条双曲线 P=V×I，曲线以外的区域全部不可用。所以「150V 和 30A」只是两条边界线，想同时站稳那个角点，需要 4500W 的散热能力，而这台机器只有 200W 或 300W。

按官方数字算一下比例：Siglent SDL1030X-E 的 300W 只占 150×30 的 6.7%；SDL1020X-E 的 200W 占 4.4%。这不是厂商缩水，是电子负载的物理形态——吸进来的功率全部变成热，散热器体积决定了那个分母。

于是真正要看的是满功率点落在哪个电压：

第四个上限：最小操作电压

翻到数据手册的额定值表，在「输入功率」下面一行，通常还有一行「最小操作电压」（Minimum Operating Voltage）。它不出现在商品页、不出现在标题、不出现在任何一张对比图里，但它决定了低压大电流场景能不能做。

Siglent SDL1000X 系列数据手册（DS0801X-C02D，文件内页日期 2019.10）两栏并排写的是 0.15V at 5A 与 0.9V at 30A。Rigol DL3000 系列数据手册的 DC Input 表更直接，把它做成一列：DL3021 是 1V@40A、DL3031 是 1.3V@60A、DL3041 是 1.5V@70A。

这一行的物理含义是：负载内部那串 MOSFET 和采样电阻本身有压降，输入电压太低时它无法维持设定的电流，实际会退化成一段接近固定阻值的负载。Rigol 在表里只给了一个点，但两点之间可以连线——把 1V/40A 理解成 0.025Ω 的下限斜率，那么在 0.75V 上，40A 档大约只能吸到 30A（这是按官方两个数字推算，不是实测）。要测 0.8V 的 FPGA 核心电、或者单节锂电放到 3.0V 截止时的 30A 放电，这一行比额定功率重要得多。

同一份产品还有代际差异。Siglent 官网 2025-08 上传的另一份 SDL1000X-C 数据手册（文件内页日期 2019.12），同一位置写的是 0.13V at 5A 与 0.8V at 30A，比 SDL1000X 低了 0.1V。两者商品名只差一个后缀，额定值完全一样（150V/30A、200W/300W），最小操作电压不同。我实际把两份手册的同一行裁下来并排放在一起，差的这 0.1V 在 30A 上就是 3W 的散热余量。买之前必须对到具体后缀那一版手册，不能只看系列名。

恒阻模式的下限不是从最小操作电压推出来的

恒阻（CR）模式常被当成「模拟一个电阻」，但它的可编程范围有下限。这个下限经常被默认成最小操作电压除以最大电流，实际并不是。

Siglent SDL1000X 的 CR 量程是 0.03Ω~10kΩ。0.9V ÷ 30A = 0.03Ω，0.15V ÷ 5A = 0.03Ω——两个电流档算出来的下限与官方 CR 下限完全重合，说明这一代产品的 CR 下限就是按最小操作电压定的。

Rigol DL3021 就不是。它的 CR 低量程是 0.08Ω~15Ω，而 1V ÷ 40A = 0.025Ω，两者差 3.2 倍。含义很具体：在 CR 模式里想拉满 40A，需要 0.08Ω × 40A = 3.2V 的被测电压；同样的 40A 在恒流模式只要 1V。拿一节 1.2V 的镍氢做 40A 恒阻放电，物理上做不到。

再回到 Siglent 那份 -C 版手册：最小操作电压降到 0.8V，CR 下限仍是 0.03Ω。0.8 ÷ 30 = 0.0267，与 0.03 不再相等。这一处不一致恰好证明了两者是两条独立的线——物理下限降了，可编程范围没跟着改。

Rigol 还在脚注里给了一条容易被漏掉的前提：CR 模式的低量程要求输入电压小于 8V（该手册 Note 5）。想用 0.08Ω 去测 12V 电源，得先切到高量程，而下限立刻变成 2Ω。

精度要除以量程读，两条脚注把 1A 排除在外

电子负载的电流精度写成 a% 加 b%FS，FS 是那个档位的满量程，不是当前设定值。所以同一个误差数字在不同电流上完全不是一回事。

Rigol DL3021 的 CC 编程精度分两档：0~4A 档是 0.1% 加 0.004A，0~40A 档是 0.1% 加 0.04A。设定 1A 时，4A 档的误差是 0.001+0.004 = ±5mA（0.5%），40A 档是 0.001+0.04 = ±41mA（4.1%）——同一个设定值，档位换一下就差 8 倍。

Siglent 用另一套写法：0.05% 加 0.05%FS，5A 与 30A 两档同样对待。1A 设定在 5A 档是 0.0005+0.0025 = ±3mA，在 30A 档是 0.0005+0.015 = ±15.5mA。它在高档位上比 DL3021 好看，代价是两个档位的固定项都不小。

然后是最容易被忽略的一条：Rigol 数据手册 Note 4 原文是「The input voltage/current value should not be smaller than 10% of the full scale」，Siglent 数据手册在 CP 与 CR 两处也写了「电压/电流输入值不小于 10%FS」。也就是说 30A 档测 1A，那个 ±15.5mA 根本不是承诺值——1A 只有 3.3%FS，落在保证范围之外。

结论不是买贵的，而是：测小电流就切小量程，别图省事留在高档位。选购时该问的是「有没有 5A 或 4A 档」，而不是「精度是 0.05% 还是 0.1%」。

回读精度同理。DL3021 的回读电流是 1mA 分辨率、0.1% 加 0.1%FS，40A 满量程下固定项就是 ±40mA；DL3021A 换成 0.1mA 分辨率、0.05% 加 0.05%FS，固定项 ±20mA。做电池容量统计时，这 20mA 会直接进积分误差。

动态频率与斜率：脚注里的斜率表只属于顶配那台

动态（瞬态）模式在两个设定值之间来回切，用来测电源的负载响应。三个数字经常被混着读：频率、斜率、最小上升时间。

Rigol DL3000 的型号表写得很清楚：DL3021 动态频率 15kHz、斜率 1 A/μs；DL3021A 与 DL3041 是 30kHz，DL3041 斜率 5 A/μs。但同一份手册的 Note 7 给了一张与电压相关的斜率表——9V 及以上 5 A/μs、8V 4 A/μs、7V 2.5 A/μs、6V 1.25 A/μs、5V 0.5 A/μs、3V 0.2 A/μs。这张表只对 5 A/μs 的 DL3041 成立；拿它去理解 DL3021 的 1 A/μs 会得出完全错误的结论。

真正值得记的是那张表的形状：斜率随被测电压下降而下降，3V 时只剩 9V 时的 1/25。也就是说「5 A/μs」这个数字只在高压段兑现，低压大电流场景里，动态性能是被电压绑住的。

Siglent 的写法反过来，把三种模式的频率分开列：CC 动态 25kHz、CP 动态 12.5kHz、CV 动态 0.5Hz。CV 动态那 0.5Hz 不是笔误——恒压模式的环路本身慢，厂商没打算让你用它做高速瞬态。真要测电源环路响应，看的是 CC 那一栏。Korad 的 KEL2000 系列在官网写「Dynamic mode: up to 10KHZ」，比上面两家都低一档。

五台在售机型的真实缺陷

Siglent SDL1030X-E

Amazon 在售的 SDL1030X-E 是 150V/30A/300W，抓取时 $1012.00。优点是数据手册给得最全：最小操作电压、CR 分档、斜率、过功率保护点（≈310W）全在表里，连电池测试量程（0.5~150V、容量到 999AH）都写明。

缺陷有三条。一是 -E 后缀把回读分辨率从 0.1mV/0.1mA 降到了 1mV/1mA，而官网两份手册的封面都叫「SDL1000X 系列」，不点进规格表看不出来。二是 CV 动态模式只有 0.5Hz，意味着它不适合做恒压侧的高速负载跳变。三是 300W 塞进 5.8kg 的机身，风扇是主要噪声源，官方未给噪声明细，放在桌边要有心理准备。

Korad KEL2010

Korad KEL2010 是 150V/30A/300W，0.1mV/0.1mA 分辨率，100 组存储，USB/RS232/LAN 三接口。它的第四种模式在商品页写作 CW，与别家的 CP 是同一个东西——乍看会以为它没有恒功率模式。

缺陷：官网产品页的规格表是客户端渲染，抓不到逐项精度与最小操作电压，只能拿到系列级描述（动态 10kHz、四模式、远程补偿）。这意味着一件很实际的事——买之前你无法从官方渠道确认它在 1V 以下能不能拉 30A。另外抓取时购买框价格未稳定返回，同页出现过明显属于配件的价格，本篇不引用它的价格，请以商品页为准。

Maynuo M9711

Maynuo M9711 是 150V/30A/150W，抓取时 $494.68。它是这五台里把 30A 和 150W 绑得最紧的机型：满功率点 5V，测 24V 电源时最大只有 6.25A。

缺陷：150W 的散热规格意味着长时间满载的温升余量最小，而商品页没有给降额曲线；30A 档在 5V 以上就再也用不满，标题里的 30A 对多数 12V、24V 场景是个无效数字。

TH8202A 与 TH8201

TH8202A 是 150V/40A/350W，$720.00；TH8201 是 150V/40A/175W，$680.00。同系列、同电压电流、价差 $40，功率差一倍。这是本篇最直接的一条选购结论：在这个系列里，175W 那一档的性价比明显吃亏，多花 5.9% 就能拿到 350W。

缺陷：两台的亚马逊商品页都只有标题里的三个数字，没有精度、没有最小操作电压、没有 CR 量程。要给客户出报告的场景，必须先去厂商处拿手册，否则测出来的数无法标注测试条件。另外 40A 在 350W 上只在 8.75V 以下成立，这层关系商品页也不会告诉你。

什么时候不该买电子负载

三种情况可以直接排除：

  • 只是想知道一个充电头输出多少瓦。USB 功率计就够，而且便宜两个数量级（FNB58 与 KM003C 的五个数字 里讲过它的量程与功率上限怎么打架）。
  • 想看的是时序和协议，不是负载能力。那是逻辑分析仪的活（DSLogic 与 Kingst 规格对拍）。
  • 想给电池充电。电子负载是单象限器件，只会吸电流，不会往外送。

剩下的场景——电源老化、电池放电曲线、适配器 OCP 点、LED 驱动纹波——才轮到它。买之前按顺序核四件事：满功率点够不够、最小操作电压够不够低、CR 下限乘最大电流是不是还在你的被测电压之内、有没有小电流档。

FAQ

问：200W 和 300W 差在哪，同样 150V/30A 为什么要多花钱？

答：只差在满功率点。300W 在 10V 以上还能继续加电流到 30A，200W 到 6.67V 就到顶。测 12V 以上负载时两者差 10A，测 5V 时几乎没差别。

问：最小操作电压 0.9V 能不能靠校准绕过去？

答：不能。它是硬件通路压降决定的下限，不是显示误差。低于这条线，设定值和实际吸流会脱钩。

问：CR 模式测 1.2V 电池，为什么拉不到标称电流？

答：CR 下限乘电流等于需要的最小电压。0.08Ω 乘 40A 等于 3.2V，1.2V 上最多 15A。要拉大电流就切 CC 模式。

问：精度写成 0.1% 加 0.1%FS，测 1A 是不是误差 0.2%？

答：不是。FS 是档位满量程，40A 档的 0.1%FS 就是 40mA，在 1A 上是 4%。并且低于 10%FS 时厂商不承诺精度。

问：单台够用还是买双通道？

答：要同时测输入和输出、或者做双路老化，双通道省一台的空间和一根电源线；只做单路放电测试，单台加一个切换继电器更便宜。

问：这些机器的价格会变吗？

答：会。本篇所有价格为 2026-11-05 抓取时商品页显示值，且本机网络出口不在美国，亚马逊可能按地区显示不同币种。下单前请以商品页为准。

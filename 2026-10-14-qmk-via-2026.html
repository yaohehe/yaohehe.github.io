QMK 还是 VIA：2026 年键盘改键位到底该走哪条路

机械键盘固件程序员

花两小时配好 Caps Lock 当 Escape、给 VS Code 绑定「跳转到定义」的手指热键，这大概是机械键盘最被低估的用法。但 2026 年这套玩法踩到了一堵墙：VIA 的官方站点 via.app 已经不是配置器了，而是一个域名出售页，标价 39,000 美元。我直接访问了这个域名，拿到的就是 Spaceship.com 的出售页。

这不代表 VIA 立刻不能用（很多键盘出厂就刷好了 VIA 固件，改键位的功能还在芯片里）。它意味着的是另一件事：当年那套「下载 VIA → 导入 JSON → 拖拽改键」的教学流程，入口已经没了。你现在搜到的多数教程都会让你打开一个打不开的网址。

本文按「你想改到什么程度」分三条路线，每条路线说清楚哪个工具能干到哪一步、哪一步必然要回到源码。文末四个 ASIN 我都实际访问过 amazon.com 商品页并解析出商品标题确认，不是凭型号推算的。价格用品牌官网口径（亚马逊页面数据在部分型号上会混入同类商品轮播的价格，不可靠），评分与在售状态会随时间变化。

TL;DR：路线一（只改几个键）→ 找 QMK/VIA 键盘，用厂商自带的启动器，最省事；路线二（要 home-row mods、Tap Dance、超过 4 层）→ 直接上 Vial，它补上了 VIA 的主要缺口；路线三（要真无线 + 长续航）→ 认清 ZMK 是另一套体系，别拿 QMK 教程套。三条路线的代价与硬伤在第三、四、五节。

五种固件，先分清谁是谁

这五个名字经常被混着讲，实际上分属三层。

QMK 是引擎。 官方站点 qmk.fm 的说法是开源、面向 Atmel AVR 与 Arm USB 家族，当前支持超过 3000 款键盘。它跑在键盘的 MCU 上，键位、层、宏都存在芯片的 flash 里，不依赖电脑上任何软件开机。代价是改一次键位就要改 keymap.c 源码、重新编译、再刷进去。

VIA 是 QMK 上的一个图形壳。 Keebio 的官方文档说得很清楚：VIA 本质上就是开启了 VIA_ENABLE 的 QMK，只是多带一个配置器，让你在浏览器里拖拽改键而不用重新烧录。注意多数键盘出厂并没有打开这个特性 —— 这就是为什么同一把键盘有人说能改键、有人说改不了。

VIA 的硬限制同样来自官方文档，且很容易被教程淡化：默认只有 4 层，想加层必须回到 QMK 编译环境；Tap Dance 这类高级特性 VIA 配置器不支持，同样要回到编译环境。另外要手动导入 JSON 定义文件才能识别键盘。

Vial 是另一个 QMK 分支，补的是 VIA 的缺口。 Pascal Getreuer 的那份指南是这一块被引用最多的文档，他的说法是：VIA 部分闭源，且看起来从 2020 年之后就没有更新；Vial 全开源且持续维护。功能上 Vial 原生多出一批东西，包括 Auto Shift、Caps Word、Combos、Key Lock、Key Overrides、Layer Lock、Repeat Key、Tap Dance，以及对 tap-hold 配置的动态编辑（Permissive Hold、Quick Tap、Chordal Hold、Tap Flow）。

但 Vial 也不是全功能。同一份文档在 2026 年 4 月明确列出它仍然缺少：per-key tap-hold 设置、Autocorrect、Key Lock、Leader Key、OS Detection、Swap Hands、Unicode 输入。文档给了补法：自己改 Vial 构建打开缺失特性。

顺带一个设计差异：VIA 需要你手动载入 JSON 定义文件，Vial 把这份元数据直接存在键盘里自动识别。这个差别在你有五把键盘要管的时候才显出价值。

ZMK 解决的是另一个问题。 官方站点 zmk.dev 的三个卖点是：基于 Zephyr、架构支持广、MIT 许可、无线优先。前两条是技术描述，第三条才是关键 —— 有第三方开发者文档解释了它的由来：QMK 的 GPL 许可与商用蓝牙协议栈不兼容，这正是 ZMK 存在的理由。

厂商启动器是第五种，它既不是 QMK 也不是 VIA。 Keychron 现在全线推的是自研的 Keychron Launcher，官网产品页把卖点写成「用 QMK 和 Keychron Launcher，随时随地在线更新和自定义键盘」。VIA 在这里已经退化成次要角色：我在 keychron.ca 的 Q6 Max 与 C2 Pro 商品页上看到的主流程是「Program with QMK & Launcher」，VIA 入口被折叠成了单独一行链接。而第三方社区项目对这套启动器的评价更直接：Keychron 固件把你锁定在 VIA 和他们的网页启动器里，想跑真正的 Vial 需要社区 fork。

路线一：只改几个键，用厂商启动器

这条路适合：想把 Caps Lock 换成 Escape、给某个键绑一个常用宏、或者纠正出厂键位报错的人。不想碰终端，不想编译任何东西。

怎么走：插线（这一步多数型号是硬要求，下面第四节会看到具体限制），浏览器打开厂商启动器，拖拽保存。

这条路的天花板：4 层。改到第 5 层就撞墙了。到时候只有两个选择：接受 4 层，或者升级到路线二。请在买之前就确认你要不要超过 4 层，不要买完再发现。

路线二：要 home-row mods / Tap Dance，直接上 Vial

这条路适合：已经在用 60% 或 65% 配列、想用 home-row mods（小指不用再承担 Ctrl/Shift 的负担）、或者想用 Tap Dance 把一个键变出三种行为的人。

这里要澄清两个常被混用的概念。home-row mods 是一种键位布置技巧（把修饰键行为放到主排字母键上），不是固件特性。而真正支撑它的固件特性叫 tap-hold / mod-tap —— QMK 文档里管它叫「一个键可以当三种东西：点按是字母，按住是修饰键，点了再点是第三种」。

QMK 的 Tap Dance 文档给出了几个具体数字，抄作业时用得上：

  • Tap Dance 默认不开，需要在 rules.mk 里写 TAP_DANCE_ENABLE = yes，代价是固件体积增加不到 1KB
  • TAPPING_TERM 默认 200 毫秒，意思是你必须在 200ms 内完成连续点击，超时就判为两次独立点按
  • 官方文档明确给了这个失败模式的原话：设了 175ms 阈值、双击要发 Enter 的例子，如果你点一下、等超过 175ms、再点一下，你得到的是 SPC SPC 而不是 ENT
  • 如果你希望 tap-dance 键比普通键更宽容，可以用 get_tapping_term() 给 tap-dance 键单独放宽 —— 文档里的示例把它放宽到 275 毫秒，理由写得很直白：作者希望普通键用短的（约 175ms），但觉得这个速度不足以可靠地完成 tap dance

这条路的天花板：Vial 仍缺 Auto Correct、Leader Key、OS Detection 等一批特性，需要自己改构建。

路线三：要真无线 + 长续航，认清 ZMK 是另一套

这条路适合：分体键盘用户、或者不接受「无线就掉帧」的人。

代价是你要换一套知识体系。ZMK 的设计目标是电池与无线成熟度，它基于 Zephyr 而非 QMK，配置方式也不同。上面第三节提到的那篇第三方开发者指南里，有一句判断值得原样引用：Q Ultra 系列的看点是 660 小时续航，但如果厂商的 ZMK 分支配了一个需要你手写 devicetree 文件才能改键的配置器，这条产品线就丢掉了一半受众 —— 而「VIA 把定制门槛压平」正是 Q 系列的卖点。买之前先确认配置器是否图形化。

排错：四个真实会卡住你的点

改键保存后没生效。 先确认是不是在无线模式下改的。上面 K2 Pro 那条官方说明已经写明：改键位只支持有线模式。用线连一次，改完再拔线。

配置器里根本认不出这把键盘。 这通常不是键盘坏了。VIA 需要手动导入 JSON 定义文件，而 Vial 靠键盘内存储的元数据自动识别 —— 所以同一个「认不出」，在两个工具里的原因完全不同。另外厂商启动器只认自家型号，第三方键盘用它当然连不上。

找不到 VIA 的下载页。 这不是你的问题。via.app 现在是域名出售页。如果你需要 VIA 配置器，得从键盘厂商的官方支持页进，或者直接评估路线二。

qmk doctor 或编译阶段报错。 官方文档给出的前置条件是装好 QMK 的 MSYS shell 环境，然后跑 qmk doctor 检查。第一步装环境比想象中麻烦，这是路线二相对路线一多出来的那部分真实成本。

FAQ

Q：现在还值得为了改键位买一把标着 QMK/VIA 的键盘吗？

值得，但要看清你买的是什么能力。标着 QMK/VIA 意味着芯片层支持，但实际能改到什么程度取决于两件事：这把键盘出厂刷的固件有没有打开 VIA 支持，以及你要的功能是否在配置器的覆盖范围内。如果你的目标超过 4 层或需要 Tap Dance，直接按路线二规划，别指望 VIA 界面。

Q：Vial 能不能装到我的 Keychron 上？

看型号。第三方社区项目的说明是：多数出厂固件把你锁定在厂商启动器里，上游 Vial 装不上去；例外是有线型号可以直接跑上游 vial-qmk，其余（无线型号、或需要 RGB / 霍尔调校 / 无线桥接的人）需要社区 fork。这是社区项目，不是厂商支持，刷写有风险且中断可能损坏固件。无线型号直接留在厂商启动器里更稳妥。

Q：home-row mods 到底值不值得学？

有第三方开发者指南把它列为 2025–2026 年最大的键盘运动，理由是它把左下角 Ctrl/Shift 的负担分散到所有手指，小指是重复性损伤的主要来源之一。它的代价也很实在：头一到两周会明显打错字，快速打字时尤其容易误触发修饰键。文档给的缓解手段是调 tap-hold 计时（从 170–200ms 起步，再按自己的打字速度缩短）以及用 PERMISSIVE_HOLD。同一份文档也提醒：home-row mods 在分体、列错位键盘上效果最好，在 60/65% 这种行错位配列上修饰键的手感「有点别扭」。

Q：为什么 VIA 只有 4 层？这个数字能改吗？

能改，但代价变了。4 层是 VIA 配置器的默认上限，想增加必须搭 QMK 编译环境并重新烧录 —— 而一旦你做了这件事，说明你其实已经需要路线二了。所以这个数字的正确用法是在买之前做需求判断，而不是买完之后再挣扎。

Q：文中这几把键盘怎么选？

如果只改几个键，K5 Max 的官方标价最低（$71.24 起），够用；如果需要无线且要多设备切换，K2 Pro 的 4000mAh 与 3 设备蓝牙比 K5 Max 的 2000mAh 更从容，但要接受「改键只能有线做」；如果看重 flash 余量和金属质感，Q1 Max 的 256KB Flash 是四款里最大的，代价是价格最高；如果你其实想要无线分体，这四款都不满足 —— Q11 是分体但只有有线。

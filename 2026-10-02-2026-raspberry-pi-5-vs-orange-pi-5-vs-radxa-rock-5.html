真实优点

  • 生态是决定性的：官方 Raspberry Pi OS、libcamera 相机栈、picamera2、海量教程和 HAT，遇到问题基本都能搜到答案。
  • 那块 PCIe 2.0 x1 接口是这代真正的亮点，接 M.2 HAT 后它能从「玩具」变成「小 Linux 主机」。
  • 双 micro-HDMI 支持双 4Kp60，做双屏桌面或数字标牌比同价位单 HDMI 的板子省事。

真实避坑

  • 主动散热不再是可选项。满载编译或跑模型时不加散热，温度很容易冲过 80 度并触发降频。
  • 必须用真正能出 5V/5A 的 27W PD 电源。用普通 65W 充电器时，USB 电流会被限制到 600mA，外接 SSD 会随机掉盘。
  • 价格是最大的槽点：同样的 8GB，两年前不到一半的钱。它贵在生态，不在硬件。
  • 内存上限锁死 16GB，且没有板载 NPU，AI 能力要靠额外的 HAT 补。

适合人群：第一次认真玩 SBC 的人、需要相机模块或大量现成教程的人、想用同一块板子跑通官方系统与桌面的人。

真实优点

  • 多核性能是真的强。RK3588S 的八核在编译、容器编排、并行转码这类负载上，比 Pi 5 的四核有明显优势。
  • 板载 M.2 x4 是这个价位段少见的配置，不用再买转接 HAT，NVMe 直插就能当系统盘。
  • 6 TOPS 的板载 NPU 让它在本地推理上有底子，不用再买加速卡。
  • 同样的内存容量，价格通常低于树莓派。

真实避坑

  • 官方 Raspberry Pi OS 跑不了，只能走 Armbian 或厂商系统；picamera2 这类树莓派专有库直接失效，依赖它们的项目要重写。
  • 多数版本没有板载 Wi-Fi，需要 USB 无线网卡或者选带无线的版本，下单前一定要看清规格。
  • 用的是 26-pin 扩展排针，不是树莓派的 40-pin，手里那堆 HAT 基本不能直插。不同来源对排针口径有出入，购买前请核对官方文档。
  • 散热不装会严重降频，这点比 Pi 5 更明显。
  • Amazon 渠道溢价明显，同一款板子不同卖家能差一倍。

适合人群：把 SBC 当 Docker 主机、NVR、媒体服务器或小型推理机，且不需要树莓派专有生态的人。

AI HAT+ 2 的真实表现：别把它当成廉价 ChatGPT

Raspberry Pi AI HAT+ 2 于 2026-01-15 发布，官方定价 130 美元。核心是 Hailo 的 Hailo-10H 加速器，40 TOPS（INT4），并且第一次把 8GB LPDDR4X 专用内存焊在了板子上——模型跑在这 8GB 里，不再吃 Pi 5 的系统内存。它通过 PCIe Gen3 x1 连接，整块芯片功耗上限约 3W，适配 Pi 5 全系（1GB 到 16GB）。

按官方与第三方汇总的口径（截至发稿）：Llama 3.2 1B 的解码速度约 30 至 50 tokens/s，Qwen 2.5 1.5B 与 DeepSeek R1 Distill 1.5B 约 20 至 35 tokens/s；而同样这些模型纯靠 Pi 5 的 CPU 只有 2 至 5 tokens/s。视觉侧，YOLOv8m 能跑到 60 FPS 以上，YOLOv8l 约 30 至 40 FPS，芯片功耗约 4.5W。

真实避坑（这部分比参数重要）

  • 知名硬件评测者 Jeff Geerling 的独立测试发现，在多数 LLM 负载下，Pi 5 自己的 CPU 反而比 Hailo-10H 更快——因为 Hailo 被限在 3W 功耗墙。它真正的价值在视觉推理，以及把 CPU 完全腾出来干别的事。
  • 同时跑视觉和 LLM 流水线时，社区报告出现过段错误（segmentation fault），软件栈还在成熟过程中。
  • 官方软件包对 Raspberry Pi OS 适配最好。我按社区教程在 Ubuntu Server 上折腾了很久，最后放弃并刷回了 Raspberry Pi OS。
  • Amazon 上这块板的第三方标价一度到过 395.99 美元，远高于官方 130 美元，下单前务必比价。
  • 它只适合 1B 到 3B 量级的量化小模型。想在 SBC 上跑 7B 以上的 agentic coding，这不是合适的平台。

踩坑录：装这三块板子时我遇到的 4 个真实报错

报错一：hailortcli scan 一个设备都不返回

现象：装完驱动后执行 hailortcli scan，输出 Hailo devices not found，或者干脆返回空列表。

原因：Pi 5 的 PCIe 接口默认没有启用，而 AI HAT+ 2 走的就是 PCIe Gen3 x1。

解决：先 sudo apt update && sudo apt full-upgrade -y，再 sudo rpi-eeprom-update -a，然后确认 /boot/firmware/config.txt 里启用了 PCIe（dtparam=pciex1，要跑满 Gen3 还需 dtparam=pciex1_gen=3），重启后用 lspci 应该能看到 Hailo 设备。具体的叠加层写法请以树莓派与 Hailo 官方文档为准，不同固件版本的参数名有差异。

报错二：dmesg 一直刷 Under-voltage detected，外接 SSD 随机掉盘

现象：dmesg | grep -i voltage 出现 Under-voltage detected! (0x00050005)，接着 USB 硬盘在编译过程中随机断开。

原因：Pi 5 需要 5V/5A 的 27W PD 电源。很多 65W 充电器在 5V 档只给 3A，甚至根本不报 5V/5A 档；一旦供电不足，USB 口电流会被限制到 600mA，外接设备就会不稳定。

解决：换用官方 27W USB-C 电源，或明确标注支持 5V/5A 的 PD 电源，同时别用超细的充电线。

报错三：sudo apt install hailo-all 报 E: Unable to locate package

现象：安装 Hailo 运行时直接报找不到包。

原因：系统源没有更新，或者你把系统换成了 Ubuntu Server——官方包对 Raspberry Pi OS 的适配最好，这也是我在 Ubuntu 上最终放弃的原因。

解决：sudo apt update && sudo apt full-upgrade -y 后重启再装；如果仍然找不到，刷回 Raspberry Pi OS（Bookworm 或更新版本）再装。

报错四：Rock 5B 点不亮或启动到一半重启

现象：接上第三方 65W PD 电源后，板子启动到一半重启，或者指示灯完全不亮。

原因：原版 Rock 5B 的 USB-PD 供电协商对市售充电器不友好，5B+ 才补上了独立的 USB-C PD 输入。

解决：优先使用官方电源，或明确支持 12V 档的 PD 电源；同时别忘了装散热，满载过热也会导致不稳定。

常见问题 FAQ

Q：Raspberry Pi 5 能跑本地大模型吗？

A：能，但仅限 1B 至 3B 的量化小模型。8GB 版纯 CPU 跑 Llama 3.2 1B 大约 2 至 5 tokens/s，加上 AI HAT+ 2 后官方口径能到 20 至 50 tokens/s。想跑 7B 以上，SBC 不是合适的平台。

Q：2026 年开发板为什么集体涨价，还会降回来吗？

A：树莓派官方在 2025-12-01、2026-02、2026-04-01 三次调价，主因是 LPDDR4/4X 内存价格上行。按第三方汇总，Pi 5 的 16GB 版从 120 美元涨到约 305 美元。官方表示市场稳定后会回调，但普遍预期 2027 年之前不会。以上为截至发稿时的公开口径。

Q：这三块板子能互插树莓派的 HAT 吗？

A：Pi 5 的专用 HAT 带 EEPROM 识别，插错会被识别为未知板；Orange Pi 5 用的是 26-pin 扩展排针，和树莓派的 40-pin 不兼容；Rock 5B 是 40-pin，物理上更接近，但驱动与电平仍需逐个确认。不同来源对 Orange Pi 5 的排针描述有出入，购买前请核对官方 pinout。

Q：在 Amazon 买开发板要注意什么？

A：三块板子的第三方溢价和库存波动都很大，同一型号不同卖家能差一倍，AI HAT+ 2 甚至出现过 395.99 美元的标价。下单前先确认卖家与配送方是品牌官方或 Amazon 自营。

Q：应该选 8GB 还是 16GB？

A：跑 Docker 加数据库加几个常驻服务，8GB 够用；要跑本地模型、开虚拟机或做视频转码，直接上 16GB。2026 年内存涨价让「先买小的以后再换」变得不划算，因为升级成本也在涨。

FAQ

Q1: USB-C Hub 显示器和普通显示器 + 外接扩展坞，哪个更划算？

A: 看你桌面设备数量。如果只有笔记本 + 显示器 + 键鼠，USB-C Hub 显示器更划算（省一个扩展坞 $80-200 + 一根线）；如果你已经有 CalDigit TS4 / Plugable 雷电4 扩展坞 + 不想换显示器，保留现状更好（扩展坞可接任何显示器）。

Q2: 90W PD 反向充电够 MacBook Pro 16" M3 Max 用吗？

A: 不够。MacBook Pro 16" M3 Max 满速需要 140W。U2723QE（90W）只能"边用边慢充"（高负载编译时会掉电）。强烈建议选 U2725QE/U3225QE/U4025QW（140W PD）才能满血充电。

Q3: U2723QE 和 U2725QE 差 $250，值不值得升级？

A: 看 3 件事：

1. 你是否需要 120Hz（不玩高刷游戏 + 不剪 4K120 视频 → 不需要）

2. 你是否需要 Thunderbolt 4（已有 CalDigit / Plugable 扩展坞 → 不需要）

3. 你是否需要 140W PD（MacBook Pro 16" 满速充电 → 需要）

3 个都不需要 → 选 U2723QE；任何一个需要 → 选 U2725QE。

Q4: 21:9 超宽屏（U4025QW）适合写代码吗？

A: 适合。VSCode / JetBrains IDE / Vim 全部支持超宽屏分屏（左右两栏代码 / 终端 + 浏览器）。但部分老软件（如某些 SSH 终端、虚拟机全屏）会强制 16:9 黑边。建议先在店里试一下。

Q5: 5K2K 显示器 macOS 缩放怎么设最佳？

A: macOS → 系统设置 → 显示器 → 在 U4025QW 上选 "更多空间"（等效 2560×1080 HiDPI）或选 "默认"（等效 3200×1352 缩放）。Wirecutter 推荐第二种（3200×1352），文字大小合适且不模糊。

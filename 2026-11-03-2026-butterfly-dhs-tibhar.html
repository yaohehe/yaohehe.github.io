套胶硬度 36、39、47.7：三套刻度与日本市场那份双标

乒乓球日亚海淘器材规格

TL;DR：

🥇 先破「数字越大越硬」这个直觉：バタフライ テナジー05（品番 05800，官方标注スポンジ硬度 36），对应的商品页是 日亚 テナジー05，我抓取时页面显示 EUR 37.93。它是 Tenergy 整条线的基准款，36 这个数比狂飚的 39 小，手感却完全不软。

🌟 粘性派的正规入口：ニッタク キョウヒョウ プロ3（品番 NR-8678），官方同时写「スポンジ硬度 42.5／中国基準 39.0」，对应的商品页是 日亚 キョウヒョウ プロ3，抓取时显示 EUR 18.91。这张双标是全文最硬的一块证据。

🔧 想看「区间表记」长什么样：ティバー エボリューション MX-P，官方硬度栏写 45,7 – 47,7°，对应的商品页是 日亚 MX-P，抓取时显示 EUR 32.38。它既不是整数也不是单值。

以上价格均为发稿时抓取。本机出口在中国，日亚页面按非日元币种显示，价格只作量级参考，不作成交价承诺。本文含日亚联盟链接，通过链接下单本站会拿到佣金，这不影响下面任何一个数字——每个数字都标了官方出处。

一、三张官方规格页摊开，问题当场就出来了

我实际做的是把三家的官方规格页逐款抓下来，一个数字一个数字抄进表格，而不是抄二手评测的结论。抄完发现一件事：这三家根本不共用一把尺。

バタフライ 的写法最省事——一个整数，没有单位，没有测试方法。红双喜的官方目录写「硬度 38/39/40/41」，也没写单位。ティバー 的官方页写「HARDNESS 45,7 – 47,7°」，带小数点、带度数符号，而且给的是一个区间。

三种写法摆在一起，你就明白为什么「哪个更硬」这个问题没法用数字回答。这不是谁不严谨，是三家各自在自己厂里建了一把尺，然后都没打算把尺借给别人。

二、Butterfly 的 36：整条产品线共用一个数，而且「硬」不等于「快」

把 butterfly.co.jp 的单品页逐款翻完，规律很清楚：Tenergy 正系全部 36，FX 副线全部 32，Tenergy 05 Hard 单独 43，Dignics 三款 40，Dignics 09C 44。

这张表里藏着两个会直接改变你选胶结果的事实。

第一个：Tenergy 05 Hard 的 43 比所有 Dignics 的 40 都硬（09C 的 44 除外）。很多人默认「Dignics 是比 Tenergy 更高一档、更硬的线」，但按官方自己的数字，Dignics 05 / 80 / 64 三款都是 40，比 Tenergy 05 Hard 的 43 软。想找硬海绵，先看 05 Hard，而不是先看 Dignics。

第二个更反直觉：硬不代表快。Tenergy 05 Hard 硬度 43，官方速度 82；Tenergy 05 硬度 36，官方速度 83——硬的那款速度反而低 1 点。Dignics 09C 是全表最硬的 44，速度 79，是全表最低。它拿到的 96 在旋转栏，和 05 Hard 并列全表最高。

所以硬度的真实含义是「海绵被压下去有多难」，它管的是你需要多大发力才能把海绵打透，不直接等于出球速度。这也是为什么「36 的蝴蝶比 39 的狂飚顶」这种说法在中文球圈里流传——它们本来就不是一个维度上的数字。

三、DHS 的 39 和 Nittaku 的 42.5，是同一张胶

红双喜的官方目录里，狂飚3 的硬度栏是 38/39/40/41，厚度 2.15/2.2mm，没有单位，也没有测试方法。这张目录由 DHS 英国代理挂出，是能拿到的一手件。

真正有意思的是日本这边。ニッタク（Nittaku）是狂飚在日本的发售方，产品名叫「キョウヒョウ」，而它的官网规格表里，硬度这一栏写了两个数：

这是全文最值钱的一张表，原因有三层。

第一层：这是官方自己承认同一个产品有两套读数。你在中文渠道看到的「狂飚3 39 度」，和日本官网上的「42.5」，说的是同一张胶，差值 3.5。

第二层：差值不固定。标准版是 +3.5，8-80 是 +4.5，8-80 パワー 是 +3.0。也就是说这不是「日本硬度 = 中国硬度 + 3.5」这种可以自己心算的换算，而是在 3.0 到 4.5 之间浮动。厂商给了两个数，但没给公式，所以你也别自己推公式。

第三层：这份双标只在日文页面上有。这是我建议在日亚买套胶最实际的理由——不是为了便宜几块钱，是因为这一页能让你把「日系数字」和「国产数字」对上号，而中文和英文渠道都没有这份对照。

顺便说个观察：TURBO ORANGE（NR-8721，45.0）和 TURBO BLUE（NR-8725，50.0）这两款，官方只给了日本侧硬度，没有给中国基準。同一张表里，给双标的都是中国原产的标准品，只给单值的是日本市场另外定的档位。这个细节反过来印证了上面的判断：双标出现在「同一个东西被两个市场分别标注」的场景里。

四、Tibhar 的 45,7 – 47,7：区间、小数点，和一个不存在的「全系 50 度起步」

ティバー 的官方 shop 页把 MX-P 写成「HARDNESS 45,7 – 47,7°」，2025/2026 官方目录 PDF 里也是同一个区间。同系列的 EL-P 是 42,4 – 44,4°。

这里有两个容易读错的地方。

第一，这是公差带，不是两个型号。45,7 到 47,7 指的是同一款胶的硬度测量落在这一段里，不是「45.7 版」和「47.7 版」。你要把它读成一个中心值 46.7 加减 1，而不是一个可以挑的范围。

第二，「挺拔全系 50 度起步」这个说法不成立。MX-P 是 45.7 到 47.7，EL-P 是 42.4 到 44.4，都不在 50 以上。ティバー 确实有一款 MX-P 50，但那是另一个更硬的变体型号，不是整个系列的下限。计划里原本就写着「Tibhar 全系 50 度起步」，我按官方页核完直接改掉了——这条是错的。

还有一层更麻烦的：ティバー 的官方速度写 125、旋转写 120、控制写 80；バタフライ 写 83/76；ニッタク 写 10.25/15.00。连「速度」这一项，三家都是三把尺。所以你在评测里看到「这块比那块快 20 点」，绝大多数时候是把两家的数直接相减算出来的，那个差值没有意义。

五、数字撞车的时候怎么判：40 对 40

Dignics 05 的官方硬度是 40，狂飚3 的 40 度档也是 40。同一个数字，两个完全不同的东西。

Dignics 05 是张力系涩性胶，海绵是「スプリング スポンジX」，官方强调变形量和回弹；狂飚3 是粘性国套，靠胶面粘性咬球，海绵偏硬、出球更依赖主动发力。把它们放在同一张表里比「谁 40 更硬」，等于拿摄氏度和华氏度比谁的数字大。

实操上我给一个不带数字的判断顺序：先问自己发力够不够把硬海绵打透，再问要不要粘性胶面带来的那种「球被黏住再甩出去」的持球感。这两个问题答完，你其实已经选完了，剩下的数字只是确认。

六、在日亚买：キョウヒョウ 就是狂飚，入口是品番

如果你在日亚直接搜「狂飚3」的日文写法，命中结果里大量是第三方品牌（EnergyPower 之类）自己贴的「紅双喜DHS」标签，不是红双喜在日本的正规发售通道。

正规入口是ニッタク 的品番。而且它自证得很清楚：キョウヒョウ3 国狂ブルー 的日亚标题里，括号中直接写着「HURRICANE III NATIONAL RUBBER BLUE SPONGE」——キョウヒョウ 就是 Hurricane，就是狂飚。

蝴蝶这边，日亚能核到单独商品页的有：テナジー05、テナジー05FX、テナジー80、テナジー80FX、テナジー64FX、ディグニクス80、ディグニクス64。其中 05FX 对应 日亚 テナジー05FX（32°，抓取时 EUR 38.31），80 对应 日亚 テナジー80（36°，EUR 39.69），80FX 对应 日亚 テナジー80FX（32°，EUR 39.69），64FX 对应 日亚 テナジー64FX（32°，EUR 38.24）。

七、成本：一张在免税线内，两张就破

按 2026-11-02 的汇率，1 美元约合 157.9 日元。日本税关的口径是：课税价格不超过 1 万日元，免征关税与消费税；超过则按课税价格的 60% 作为计税基础，再叠加关税与 10% 消费税。

拿ニッタク キョウヒョウ プロ3 算：官方定价 ¥5,000（税抜）／¥5,500（税込）。单张在 1 万円以内，落在免税区间；买两张就是 ¥11,000，直接破线。套胶这东西一张只能贴一面，正反手配置本来就是两张起，所以「破线」几乎是默认状态，别按单张的账去估到手价。

两个例外和一条到期日必须记住：皮革制品与皮革鞋类不适用这条免税；財務省改正案写的是 2028-04-01 起取消个人进口小包的免税。套胶不是皮革鞋，享受免税线，但这条线本身有到期日。

八、取证边界，和一次自我修正

计划里原本写着「Tibhar 挺拔用德系 DIN 刻度且全系 50 度起步」。前半句方向没错（确实是另一套刻度），后半句被官方页直接推翻：MX-P 是 45,7 – 47,7，EL-P 是 42,4 – 44,4，没有「50 起步」这回事。我把这句话改成了现在这个版本，也把「DIN」这个词删了——ティバー 官方页面只写 HARDNESS 加度数符号，没有任何一处自称 DIN 刻度，我不能替它认领一个标准。

还有几个型号我没能核到日亚单品页：Dignics 05、Dignics 09C、Tenergy 19、Tenergy 64、Tibhar MX-S。搜索命中的基本是「セット買い」的套装组合页，或者干脆没有结果。这几款我只引官方规格，不给购买链接——按本站的规矩，拿不到商品页标题的型号不写进正文推荐位，宁缺不乱挂。

另外提一句：バタフライ 的 Dignics 系列官方标注是「オープン価格」（开放价格），没有厂商希望零售价。所以你在任何地方看到「Dignics 05 官方价 XXXX 日元」，那个数是渠道价，不是官方定价。本文里蝴蝶侧的价格全部来自日亚抓取页，不是官方定价。

九、按你的打法选，不按数字选

IF 你发力一般、想把球稳稳拉上台 → 蝴蝶 FX 线（32°）或 キョウヒョウ プロ3（42.5／39.0），别碰 44。

ELSE IF 你已经在主动发力、嫌胶皮打不透 → テナジー05（36°）起步，需要更硬的支撑再上 05 Hard（43°）。

ELSE IF 你要粘性胶面那种持球感 → キョウヒョウ 线，标准版 42.5，想要更硬就 TURBO ORANGE（45.0）、TURBO BLUE（50.0）。

ELSE IF 你有预算压力又想要张力系手感 → MX-P（45,7 – 47,7°），它是这批里价格最低的张力系。

ELSE → 先买一张正系加一张 FX，同一块板子上对比，比看十篇评测快。

球拍那一头如果还没定，可以看 日亚 1 万日元档的球拍路线；如果你更大的困惑是「为什么日本型号和美国型号对不上」，那篇讲 日英型号谱系与品番读法 更对症。

常见问题

Q：Butterfly 36 度真的比狂飚 39 度硬吗？

A：不能这么问。两边是两把尺：蝴蝶是自家整数刻度，狂飚是国产硬度档位。日本官方页给出的锚点是「42.5 对应中国基準 39.0」，也就是狂飚 39 在日系表上大概落在 42.5 附近，比蝴蝶的 36 高。但这是厂商标注的对应关系，不是手感等价。

Q：为什么同一个品牌不同型号的硬度会一模一样？

A：因为硬度只是海绵的一个参数，厂家用它做产品线分层。Tenergy 正系全部 36、FX 全部 32，靠齿粒形状（No.05／No.64／No.180／No.219）和海绵配方区分手感，而不是靠硬度分档。

Q：日亚页面显示的不是日元，怎么算到手价？

A：本机出口 geo 不在日本，日亚会按其他币种显示。建议按「官方日元定价乘汇率加国际运费加可能产生的关税消费税」自己算，别拿显示价直接当成交价。

Q：套胶有没有保质期，海淘囤货可以吗？

A：官方没有给套胶标注保质期，但张力系胶皮的海绵内能会随时间衰减，这是物理事实而非厂商承诺。囤货建议不超过一个赛季的量。

Q：为什么不给 Dignics 05 和 09C 的购买链接？
